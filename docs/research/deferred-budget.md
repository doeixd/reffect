# Deferred automatic-yield admission audit

Recorded 2026-10-04 against published and installed **Effect 4.0.0**. This supplements TURN-009/010 and DEFCORE-004. Read AGENTS, PLAN/PROGRESS, deferred-turns/core and the current plain/framed `effect-ir.ts` evaluators before this audit. Retrieved [published internal evaluator](https://unpkg.com/effect@4.0.0/src/internal/effect.ts) online and compared the relevant definitions with installed source. Primary references: [core primitives](https://unpkg.com/effect@4.0.0/src/internal/core.ts), [scheduler](https://unpkg.com/effect@4.0.0/src/Scheduler.ts), [Deferred](https://unpkg.com/effect@4.0.0/src/Deferred.ts).

## Decisions and boundaries

**DBUD-001 — Conditional, private analysis only.** The checker is not selected by the compiler and does not admit public Deferred. Its contract assumes the default MixedScheduler with the default 2048 budget, default Clock/Tracer, no tracer-context or metrics hooks, and synchronous loggers that do not evaluate effects in the current fiber. It analyses valid zero-input Effect functions, with at most one external `Effect.exit` observer and no further effectful host wrapping. Custom services/scheduler contexts and input Schema decoding have no established weight. A future integration must enforce these assumptions, audit the actual Deferred interpreter expansions, and retain independent ownership/cohort/cause gates. A conditional finite result is not unconditional native compatibility.

**DBUD-002 — Whole-invocation expansion bound.** Charge operation occurrences, not unique IR identities. Add sequential, recovery and cleanup paths; take maxima only between mutually exclusive Match alternatives. Sum child fibers as well, deliberately overcounting independent evaluation turns. Stop arithmetic at 2048 and reject a bound reaching it. No runtime metadata or scalar wrappers are introduced. Infinite/unaccounted operations are rejected rather than assigned a guessed per-node constant. Context-independent summaries are memoized, but each incoming edge adds its full summary; this avoids exponential traversal of shared DAGs without undercounting occurrences. Active recursion rejects cycles.

`FiberImpl.runLoop` increments once per primitive and resets at `evaluate`; `succeedWith` adds one and can materialize an extra Success every 32 calls. Charge map as three (OnSuccess + succeedWith + possible Success). Suspend is one, Success/Failure one, expression try two, flatMap wrapper one, framed catchCause decoration two. Continuation stack scanning, synchronous JS callbacks, forkUnsafe construction, observer registration and ordered cohort iteration are not evaluator primitives. Returned effects are charged separately.

**DBUD-003 — Entry receipt, 24 operations.** For a valid zero-input reference invocation, named Effect.fn expands to three WithFiber evaluations: update CurrentStackFrame, useSpan, and provide ParentSpan. Context restoration finalizers each return the original exit: charge three WithFiber plus three returned exits = 6. The generator wrapper contributes Suspend + Iterator + terminal Success = 3. Span end contributes finalizer FlatMap + Sync (one evaluation plus produced Success) + retained exit = 4; its failure combine wrapper, pending-interruption restoration and final failure contribute at most 3 more. Framed Effect.exit and an optional external Effect.exit each cost at most three (Exit evaluation, succeedWith, possible Success), hence 6. Charge two additional failure exits for interruption entering or leaving the named wrapper. Total 6 + 3 + 7 + 6 + 2 = 24. This sums incompatible success/failure paths and the plain invocation's absent framed observer. Default span/clock implementations run synchronously. No arbitrary tracer, hook, schema or outer host continuation is covered.

**Group receipt.** All is forEach Suspend followed by iterateConcurrent callback and final as wrapper/Success (4). Race is WithFiber plus callback (2), overcounted by the same 4. Child forkUnsafe and observers are synchronous JS; charge each child two possible injected interruption/terminal failures. On interrupted Async cancellation, returned cleanup expands to Suspend, outer FlatMap, fiberInterruptAll WithFiber, asVoid wrapper, fiberAwaitAll callback, terminal Success and retained terminal (7). AsyncFinalizer can add combine OnFailure, outer FlatMap, retained Fail and restoration Fail (4). Await-all interruption cleanup adds Sync + produced Success, combine OnFailure, FlatMap, retained Fail and restoration Fail (6). OnExit draining additionally contributes FlatMap, combined-failure wrapper and returned exit (3). Summing all these alternative drains yields 4 + 7 + 4 + 6 + 3 = 24, plus 2k. Most paths are mutually exclusive; summing them intentionally dominates success, failure and parent cancellation. Group children must themselves have finite weights. Source paths audited: forEach/iterateConcurrentImpl, raceAll, forkUnsafe, callbackOptions/asyncFinalizer, fiberInterruptAll/fiberAwaitAll, OnExitImpl and setInterruptible. This is budget accounting, not admission of nested group topology or cancellation semantics.

**Sleep receipt.** Sleep adds outer Suspend + clockWith WithFiber (2). Default Clock's <=0 branch returns yieldNow; the timer branch adds callback and eventual void Success (2). Interrupted callback cleanup contributes Sync + Success, combine OnFailure, FlatMap, retained Fail and restoration Fail (6). Charge four additional primitive slots for explicit Yield evaluation, resumed Success and entering/leaving interruption failures (at most four); total 14. Timers larger than MAX_TIMER_MILLIS recursively schedule more callback primitives and are refused. Custom Clock can return arbitrary Effects and is outside this proof.

**DBUD-005 — Unaccounted means refused.** Scope, AddFinalizer, AcquireRelease, brackets/files, Ref, driver reads, Launch/Remote, streams, Repeat/Retry/ForEach, attributed logs, annotation/span wrappers and future Deferred nodes remain unaccounted. These may have finite implementations, but their own complete receipts are absent from this audit. Never infer a proof from small observed counts. In particular, Scope finalizer iteration and input Schema effects require explicit cardinality/implementation boundaries. Adding a node cannot silently inherit a default constant.

## Validation

Private unit checks verify caps, shared occurrences, branch maxima, recovery/cleanup sums and refusal paths. A public MixedScheduler subclass records `fiber.currentOpCount` while delegating every yield decision to super; tests compare source bounds with actual plain/framed counts for scalar/maps, failure/recovery, nested Ensuring and fixed All/Race loser cancellation plus root/group parent cancellation. `runForkWith` eagerly calls evaluate before returning; the parent-interruption fixture asserts the fiber is still pending after both finalizers are installed, then interrupts it. Fixtures on either side of the 2048 admission boundary verify the checker, and a longer map chain independently demonstrates actual automatic yielding. The upper-bound fixture need not itself yield: conservative refusal is expected. Instrumentation is corroboration, not the proof.

The default-context assumptions, absent Deferred receipts, ownership integration, retained-error behavior and full authored differential conformance remain release gates. This work changes no compiler-selected support or generated Rust.

Focused validation completed: deferred-budget.test.ts **5/5**; scoped Vite+ formatting/lint/type check passed; strict package TypeScript passed. These results verify only the private conditional analysis and corroborating probes.
