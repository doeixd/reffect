# Standalone Deferred execution boundary

Prepared 2026-10-05 before implementation. Reviewed DBUD/DADM, private generated profile/reference, the named plain/framed evaluator and current budget probes. Synced through 9c3a6ee and installed dependencies. Checked published [Effect 4.0.0 evaluator](https://unpkg.com/effect@4.0.0/src/internal/effect.ts) and [scheduler](https://unpkg.com/effect@4.0.0/src/Scheduler.ts) against installed source. Independent context findings are recorded in [the audit](deferred-context-audit.md).

**DEXEC-001 — Own the host boundary.** A private standalone Promise runner validates the full generated Deferred profile before starting a fresh root fiber. It passes a fresh default MixedScheduler, explicit 2048 operation limit and automatic yielding enabled through a runner-owned context. It inherits no caller Effect context, continuation, clock, tracer, span, metrics hook or input decoding. Default Clock/Tracer behavior is resolved by official Effect from that context. Returning an Effect would permit arbitrary host wrapping; returning Fiber would permit context mutation. Neither is returned.

**DEXEC-002 — Close options and observation.** The only accepted execution option is a same-realm AbortSignal. Refuse unknown keys, custom prototypes/accessors and injected runtime options before evaluating IR; TypeScript callers also see only the cancellation option. Use a runner-owned synchronous logger that copies messages into immutable output, with no caller logger or callback. Context creation and Promise observation are host operations, not extra evaluator primitives. Both plain/framed execution reuse the existing named reference evaluators directly, retaining audited entry receipts. Global monkeypatching of Effect defaults, runtime methods or host platform behavior is outside the normal library contract.

**DEXEC-003 — Cancellation before and during execution differ.** Official runForkWith eagerly evaluates before handling RunOptions.signal; therefore a pre-aborted signal must be checked before starting this runner's interpreter. It returns an interrupted outer Exit and no logs. Cancellation of a suspended invocation uses official interruption and awaits its cleanup through runPromiseExitWith. A framed observer that never starts cannot fabricate authored frames. Exact native/reference interruption trails remain a separate gate; no public Deferred admission follows from this boundary alone.

**DEXEC-004 — Prove enforcement and budget margins.** Tests must refuse injected scheduler/context/yield/hook options before source work, isolate ambient custom Clock/Tracer/Scheduler/loggers, preserve normal retained completion and cleanup traces, and enforce both sides of the 2048 bound. Corroborate actual operation counts by a test-only delegating probe of the default scheduler method; do not accept a user-supplied scheduler assertion or suppress automatic yielding. Retain the existing independent long-workload witness that the official default scheduler really yields. The internal Effect-valued entry remains explicitly conditional for controlled-clock conformance research.

**DEXEC-005 — Close expression callbacks too.** Review finds that `Operation.reference` is extensible JavaScript, invoked synchronously inside the expression evaluator. An arbitrary custom operation can reenter execution or perform host effects despite having a scalar signature. The standalone boundary therefore accepts only builtin scalar/string/number witnesses and exact builtin operation objects, with Literal/Parameter/Apply/Boolean Match expressions. Reject custom operations, witness aliases and compound expression forms before general profile validation or interpretation; identity by display name or semantic ref alone is insufficient. Existing private interpreter/lowering support remains conditional and unchanged. Broader expression providers require a separate trusted implementation contract.

Alternatives rejected: inspecting a fiber after runFork/onFiberStart (it has already evaluated); instanceof MixedScheduler (allows subclasses/custom dispatchers); forcing PreventSchedulerYield (changes the reference profile); resetting the operation counter inside an ambient fiber (changes scheduling semantics); accepting arbitrary Context or logger options (reopens unbounded primitive/hook expansion). Public authoring, rich channels and general graph storage budgets remain separate work.

## Delivery and validation

The internal `DeferredExecution.run/runWithFrames` accept only zero-input Never-error functions and a closed cancellation option. Complete private-profile validation happens before starting any fiber. Invalid options return a structured DEFERRED_EXECUTION_CONTEXT failure with no logs; accessor options are rejected without invocation, and a prototype-only AbortSignal lookalike fails a native brand check. Successful execution constructs a fresh scheduler/context and returns frozen observations. Neither a mutable Fiber nor a logger callback is exposed. The old Effect-valued reference entry and public compiler admission are unchanged.

`vp test packages/reffect/tests/deferred-execution.test.ts packages/reffect/tests/deferred-budget.test.ts packages/reffect/tests/deferred-integration-admission.test.ts --maxWorkers=1` passes 18/18 (3.78s). The tests cover retained first completion, plain/framed results, immutable logs, injected options and pre-abort validation, default service isolation, interruption awaiting asynchronous cleanup, abort after synchronous completion, and independently authored official registration-order traces. A test-only delegating scheduler-method probe observes the real owned scheduler with 2048/false, no metrics/tracer hooks and no automatic yield below admission; above-bound programs never start a fiber. The existing budget suite independently demonstrates actual automatic yielding for a longer ordinary reference workload. Strict package TypeScript passes.

This boundary owns TypeScript execution context and observational log storage. It adds no native metadata field, scalar wrapper, Rust runtime or dependency. General embedding into a caller's Effect graph, public context-policy integration, exact interrupted diagnostic trails and richer outcomes remain open. Controlled TestClock experiments remain conditional research; they do not bypass this production default-context contract.
