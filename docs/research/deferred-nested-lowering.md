# Private nested Deferred helper lowering

Prepared 2026-10-05 before feature edits. Reviewed AGENTS, PLAN/PROGRESS, DGEN/DHELP, DIN/TURN and HCAP records, lexical capture selection and helper memoization. Checked installed Effect 4.0.0 against the published [internal source](https://unpkg.com/effect@4.0.0/src/internal/effect.ts), fetched online and byte-identical on this date. Its `raceAll` forks children in input order, chooses the first success, and registers loser interruption on parent exit; cleanup must finish before the enclosing race releases its lifetime. Never-error Unit children avoid extending the retained compound-failure representation. Tokio 1.53.1 and Rust 1.98.1 remain the existing substrate/profile.

**DNL-001 — Allocate bounded contiguous task subtrees.** The private topology analysis supplies each computation's maximum live context capacity: a group owns one ancestor context plus the sum of child capacities; sequential and alternative work takes the maximum. Each group reserves child intervals immediately above its current slot. Siblings receive disjoint intervals, nested ancestors retain their own slots, and sequential groups reuse the same intervals only after their children have drained. Capacity belongs to build-owned analysis; native scalars and AsyncContext gain no fields.

**DNL-002 — Preserve occurrence-sensitive helper routing.** Private Scope carries its current task slot through binder scopes, capture filtering and lexical owners. Each group child receives a fresh Scope identity with its assigned slot. Existing node/scope/error helper memoization therefore separates a shared computation used under distinct live task contexts. Group helper bodies record child slots, exclusive interval ends and the parent slot; emission does not infer ancestry from generated names.

**DNL-003 — Reuse the selected driver family.** Calls pass bank, child slots, exclusive ends, parent slot, fixed child futures/cancellation senders, parent cancellation/mask and All/Race mode. Children retain the existing whole-task semantic acknowledgement wrapper. Ancestor routing and aggregate suspension propagation belong to the verified driver, while helpers continue to wrap only primitive Sleep/Await. Race success ignores canceled losing children but waits for their cleanup. No Box, spawn, owner registry, TLS, erased pointer or per-value metadata is introduced.

**DNL-004 — Keep the widening private and bounded.** Ordinary lowering/public admission and ordinary emitted artifacts remain unchanged. Reuse scalar/owner capture pruning and provenance. The admitted widening is an outer All2/3 with at most one initially started Race2, at most six live contexts, Never-error scalar owners and Unit group children. Nested All, deeper/multiple nested races and masked cleanup group startup remain refused. Callback-started groups and masked cleanup group startup stay refused pending separate proof. Forced host Drop/panic remains unsupported. Nested Race does not imply public scheduler-context enforcement or richer Cause support.

Alternatives rejected: globally unique slots for every syntactic group (inflates capacity despite sequential lifetime reuse); reuse slots 1..arity at every nesting level (aliases live ancestor/sibling identities); infer ancestry from helper IDs (helper identity is distinct from runtime task identity); dynamic heap task registries (unnecessary for checked fixed topology).

Acceptance: inspect distinct static routes for shared nodes and nested/sequential groups; compare independent official/plain/framed/generated traces for canceled waiter isolation, synchronous and awaited cleanup and finalization signals; compile actual emitted Rust under both frame policies and debug/release; preserve parent cancellation, ordinary artifact omission and the existing quiet zero-allocation checks. Root records integrated validation and remaining gates.
