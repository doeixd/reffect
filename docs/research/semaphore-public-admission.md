# Bounded public Semaphore admission

Prepared 2026-10-06 against Effect **4.0.0**, Rust **1.98.1**, Tokio **1.53.1**. This extends [private scan/All evidence](semaphore-native.md), [structural receipts](../../packages/reffect/src/semaphore-structure.ts), and the [owned Deferred boundary](deferred-public-execution.md). Existing private conformance is necessary but does not establish generated support.

## Primary evidence

Rechecked published [Semaphore](https://unpkg.com/effect@4.0.0/src/Semaphore.ts), [evaluator](https://unpkg.com/effect@4.0.0/src/internal/effect.ts) and [Scheduler](https://unpkg.com/effect@4.0.0/src/Scheduler.ts), and installed source. Semaphore/evaluator published files match the installed version. Release schedules a live observer scan; suspended observer resumption synchronously evaluates its continuation. A new runLoop resets its operation counter. Evaluator steps and succeedWith increment it; default automatic yielding starts at 2048 operations. Scan iteration/fork/observer machinery is synchronous JavaScript, but resumed acquisition and cleanup Effects still cost evaluator steps.

Reviewed generated Deferred helper captures, owned options/trusted-expression audit, diagnostic path plans, actual-future layout assertions, and the private Semaphore drivers. All already converts child Unit results to success/interruption bools. Never-error All discards child failure trails, so root interruption observers and masked finalizers must retain the existing diagnostic policy.

## Decisions

- **SPUB-001:** admit only checked standalone zero-input Bool/U64/Unit-success, Never-error functions with exactly one root lexical capacity-1..3 owner, at most one unnested All2/3, and one permit per acquisition. Preserve nonescaping handles, no nested guarded acquisition and no group/acquisition in cleanup. All under a held guard remains safe only because children cannot acquire. Mixed Deferred, services, SQL, dynamic fibers, typed failure/defect carriers, manual permits and richer resource lifetimes remain refused. Builder configuration can be broader than native admission, with explicit diagnostics.
- **SPUB-002:** add separate audited Semaphore reference budgets. Whole-invocation sums below 2048 conservatively bound every turn, including callback resumptions. Proposed primitive upper bounds: invocation24; owner4 plain/6 framed; acquisition8/10 plus body; All24+2k/26+2k plus children; each conservative registration/retry episode12. Use `R = acquisitions + waiterCapacity × releaseScans` globally. Preserve audited ordinary Deferred atoms without accepting Deferred nodes. Framed root observation charges the existing masked-observer allowance20 per observed node; children discarded by infallible All and masked finalizers use their established observer policy. Saturate and refuse unaccounted nodes, attributes, timers outside0..2147483647 or context changes.
- **SPUB-003:** generated-only asynchronous waits are acquisition and Sleep, both explicitly marked by `ScanTask.semantic` and polled unconstrained. No generic-future assumption can justify retry ceilings. Certify those generated Pending sources, derive finite retry/scan/settlement bounds, and pass them into the runtime emitter while retaining private defaults for old research fixtures. Release-created pending scans are bounded by releases; selected callback tickets by R; terminal/parent settlement triggers are monotone and bounded. Do not replace64 with a guessed2048.
- **SPUB-004:** public owned Promise execution uses a fresh official MixedScheduler with default yield policy, captured logs, trusted builtin identities, a closed optional same-realm AbortSignal and explicit pre-aborted preflight. No ambient context/hooks or mutable Fiber escapes. Reuse shared audits/diagnostic observers without broadening Deferred admission. Public framed interruption must match generated root/helper paths after awaited cleanup, including SemaphoreScope and WithPermits boundaries.
- **SPUB-005:** lower borrowed owners and marker banks inline, prune captures, copy scalar captures and borrow pinned child futures. A permit remains alive through the entire guarded result, including masked asynchronous Ensuring, and is released once before result propagation. Select the separate scan All driver, preserving ordinary/selected parent cancellation phases and bool status distinct from Unit payload. No authored scalar receives resource/metadata fields or heap indirection.
- **SPUB-006:** actual generated returned root future must pass a native code-generation layout assertion, including owner/bank/context/child storage, under both frame policies. Bound per-function structural/source growth, per-coordination-family module aggregate growth and jointly emitted Rust bytes independently. SourceArtifacts and FailureFrames opt-outs remain independent and do not relax semantic receipts. Public R/package exports follow complete generated conformance, not prototype success; native host/RPC embedding remains a separate integration gate.

Alternatives: FIFO reservation/wake-all already have ordering counterexamples; using tuple collection loses All interruption; disabling automatic yielding or exporting arbitrary execution hooks evades semantics. Extending trusted Deferred dispatch without joint evidence enlarges its proof boundary. Separate selected Semaphore lowering reuses existing representation/ownership facilities and limits semantic runtime to the live-scan protocol.

## Acceptance and remaining checks

Implement receipts and owned execution first, integrate compiler/lowering behind those checks, then expose the bounded builders/runner. Compare public authored IR through fresh official execution with actual generated Rust for suspended contention, release continuation/barging, capacity, masked holder and sibling cleanup, preflight/during-work cancellation, framed interruption and disabled-frame behavior. Include mixed ordinary/Deferred module regression, malformed/escaped/untrusted references, profile/budget/growth refusals and native layout checks; compare debug/release. Measure incremental quiet owner/driver allocation separately from watch/context construction. Keep native builds sequential. Any discovered gap stays refused and is recorded here and in open work.

## Reference budget audit detail (2026-10-06)

`semaphore-budget.ts` is a separate conditional receipt. It first requires the structural profile, including finite occurrence/depth bounds and valid checked IR. It does not extend Deferred's accepted nodes. Ordinary primitive weights come from [DBUD-002–004](deferred-budget.md); custom callbacks still require the shared builtin identity audit before execution/admission. Attributed logging and custom context declarations are refused. Invalid timer configurations may fail the preceding IR check before receiving a budget-specific diagnostic.

The wrapper's release callback calls `releaseUnsafe` and returns `undefined`: it contributes a retained Exit rather than an evaluated release Effect. The live Set scan and terminal/fork observers themselves are JavaScript callbacks, not evaluator primitives. Returned and synchronously resumed Effects remain charged. Each initial registration belongs to one acquisition occurrence; detached retries are bounded conservatively by waiter capacity times scheduled release scans. Fresh acquisition registrations inside a live scan are included in the acquisition term rather than asserting a fixed callbacks-per-scan bound. Add the global allowance `12 × (A + W × S)` once, plus invocation24 and recursively expanded node receipts. Success/cancellation alternatives are intentionally summed.

`runLoop` resets `currentOpCount` each time it starts, including synchronous waiter `resume` calling `fiber.evaluate`. Each primitive evaluation increments it; `succeedWith` increments it and can return an additional Success every32 inline calls. A whole-invocation sum over all fibers and all resumptions strictly below2048 therefore dominates every individual scheduler turn. Shared incoming edges contribute full summaries; branch alternatives take componentwise maxima. Framed interruption observation adds20 per observed node. All children and masked finalizers use observationfalse, matching the established infallible/discarded-trail policy.

The immutable driver receipt supplies retry1, scans`max(1,S+1)`, callbacks`R`, settlement3. Retry1 is conditional on the generated lowering certifying that every Pending source is an explicitly marked semantic wait, with unconstrained polling; it is not a guarantee for arbitrary Future implementations. The scan bound includes the terminal empty check. Settlement requests arise from the first terminal child and the first parent cancellation; both flags are monotone, so three rounds conservatively cover an initial request plus both triggers. Refused analyses expose no driver bounds.

Tests exercise shared incoming edges and branch execution maxima, a balanced shared-guard graph crossing the2048 receipt threshold, public scheduler observations below the accepted receipt, and parent interruption of All with contending waiters and asynchronous masked cleanup. These observations corroborate source receipts; they do not establish callback identity, generated semantic-marker correctness, or layout.

## SPUB-007: concurrent timer admission

Review found that static child polling can resume a later-deadline timer before an earlier-deadline sibling when both deadlines pass before the parent is polled. Semantic Pending markers identify real suspension but do not identify which child woke. Therefore the first public generated and owned profile admits at most one Sleep-bearing child per All, counting both ordinary bodies and masked finalizers and all source branches conservatively. Other children may contend for permits and run synchronous bodies/cleanup. Sequential sleeps in that one child remain supported. This is an admission restriction, not an accepted runtime divergence. Multiple independently sleeping children require a verified wake/deadline-aware driver before admission; preserving inline scalar and owner storage remains a cost goal, not a reason to accept changed event ordering.

## Generated allocation boundary

The first full-root allocation probe found two allocations per quiet generated All2 invocation: its two Tokio child cancellation watch channels are constructed inside the root. Earlier private borrowed-driver zero-allocation measurements excluded watch/context construction, so they cannot be applied to a complete generated All invocation. Quiet scalar guarded roots allocate zero after parent context construction; quiet All2 roots allocate two, with owner, marker bank, scalar payloads and pinned futures remaining inline. These measurements exclude logging, timers, interruption-frame allocation and initial Tokio/parent-context setup; full invocation and compiler peak-memory measurements remain open.

## Delivery and revisit gates

The bounded profile is public through `R.Semaphore`, `SemaphoreIR` and `SemaphoreExecution`. Public compiler→Cargo→NativeRunner tests compare scalar and contended All exits against owned official execution with FailureFrames.None/Bounded, including independent ordinary and Deferred exports. Generated debug/release execution checks cancellation after suspension, awaited masked cleanup, retained scalar captures, the three root All/owner/function interruption boundaries and actual returned-future layout enforcement (limit2560 pointer-sized words). SourceArtifacts.None and Full emission are exercised independently. Native scan/task/All and public Deferred regressions pass sequentially.

Independent review corrected the new timer restriction to match the actual TaskGroup IR tag; refusal tests include timers in finalizers. Remaining gates are independent timer wake routing, native RPC context integration, manual/multiple permits, richer inputs/outcomes, nested/mixed coordination and full compiler/invocation memory measurements. This profile does not export the rejected raw wake-all prototype or make the private fixed-driver defaults into public admission evidence.
