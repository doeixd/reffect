# Private owned Queue reference execution

Prepared2026-10-07 against AGENTS, PLAN/PROGRESS, QBUD/QGEN, the existing Latch/Semaphore/Deferred owned runners and interruption-frame planner. This establishes the default reference context for the private generated offer/take profile; public exports and native frame policy remain unchanged.

## Decisions before implementation

- **QEXEC-001 — Owned boundary, private entry.** Add internal QueueExecution.run/runWithFrames using the checked generated profile, trusted expressions and QBUD receipt before execution. Require zero inputs, scalar/Never channels, one bounded root Queue and unconditional All2. Ordinary functions and broader Queue operations stay refused. Start from Context.empty with fresh MixedScheduler, MaxOpsBeforeYield2048, PreventSchedulerYieldfalse and a captured synchronous logger. Ambient services, tracer hooks, loggers and host continuations do not enter the invocation. Do not export QueueExecution or enable public Compile.
- **QEXEC-002 — Cancellation before source work.** Accept only plain options with an optional same-realm, intrinsically brand-checked AbortSignal; inspect property descriptors without invoking option getters. Preserve specific profile diagnostics. Check intrinsic aborted state after profile validation and before evaluating authored code. An already-aborted call returns an interrupted outer Exit and no logs or opened frame boundary. Forward a live external signal into an invocation-owned AbortController using intrinsic EventTarget methods, then give only the owned signal to Effect. This avoids external signal getters/overridden listener methods entering the audited context. Remove forwarding listeners on settlement and synchronous start errors. Promise observation/context/signal setup stays outside the evaluator budget.
- **QEXEC-003 — Reference frames only.** Reuse the existing scope-indexed DeferredInterruptionFrames planner, which already handles Queue. Bounded logs and frames belong to each invocation, never scalar payloads. All children retain framed decorations but omit parent interruption observers. Interrupted group observations therefore retain parent All/QueueScope/function trails, not child Queue wait trails. Successful framed results use the existing outer Exit containing FramedExit convention. Reconcile root-only interrupted exits through the recorded trail as existing owned runners do. Native FailureFrames.Bounded remains explicitly refused until generated parity exists.
- **QEXEC-004 — Conformance and handoff.** Compare owned outputs/logs with raw official reference for pressure/capacity/payload/captures and cancellation. Use the owned runner in generated Queue differential tests while retaining a separate raw comparison in execution tests. Test ambient context isolation, fresh owners, immutable observations, preabort, blocked offer/take settlement, frame paths, listener removal, accessor/forged options and trusted-reference/growth/budget refusals before authored logs. Keep native builds serial, existing public refusal tests and native layout/allocation gates.

## Alternatives and remaining gates

An Effect-valued wrapper inherits arbitrary host continuations and cannot enforce QBUD assumptions. Public Queue exposure now would mistake reference-frame evidence for native-frame parity. Copying the existing cancellation boundary without isolating external signal access can run user-defined signal getters/listener methods around eager evaluation; the owned forwarder is intentionally local rather than a broad refactor of shipped runners.

Generated interruption frames/Cause/Exit, Done/shutdown/fail-fast, Ensuring/Sleep mask markers, broader ownership, RPC/Send and host-future abandonment remain separate. This work does not add native runtime fields, expand the profile or guarantee a blocked function terminates without cancellation.

## Follow-up discovered during review

Existing Deferred/Semaphore/Latch owned runners intrinsically brand-check external signals but later read their ordinary aborted/listener properties and pass them directly to Effect. A genuine signal with a shadowed aborted getter can conceal preabort, and shadowed listener methods can execute hooks. Independent review reproduced the ordinary-versus-intrinsic state mismatch. Queue's relay isolates those properties; porting it to the existing runners remains a linked open item rather than changing their public boundaries in this unit. Arbitrary global runtime monkeypatches and host Proxy traps are outside the trusted native-signal assumptions.

## Delivered evidence

Internal run/runWithFrames apply the checked private profile before source work, isolate the reference context and retain invocation-local parent interruption trails. Eight execution tests include an independent raw oracle, controlled pending cancellation, exact parent frame paths, external signal override isolation, preflight options/profile/budget refusals, concurrent invocation isolation and forwarding-listener retirement. Removing settlement retirement fails the listener test; correct source is restored. Generated debug/release Queue differential uses this owned runner, with the earlier native continuation mutation, layouts and zero-allocation exclusions unchanged.

Independent review found no blocker in cancellation ownership, observer costs and the private reference/native boundary. All61 tests across8 source/reference suites and the native generated Queue test pass. Full strict TypeScript, workspace formatting/lint/type check and builds accompany source/native regression validation. Broader profiles and public/native frames remain refused.
