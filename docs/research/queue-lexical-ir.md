# Private lexical Queue IR

Prepared 2026-10-06 before implementation. Read [QBF](queue-bounded-foundation.md) for the pinned Effect4.0.0 lifecycle and private native protocol; this slice adds authoring/reference semantics, not generated or public support.

## Decisions

- **QIR-001 — Typed lexical owner.** Intern Queue witnesses by payload/error semantic identity, with channel metadata on compiler-owned witnesses rather than runtime values. Kernel pure-marker checks use local marker recognition to avoid a kernel-to-Queue witness initialization cycle; higher passes use canonical Queue helpers. Initial payloads are Bool/U64/Unit; errors Never or a distinct unit Cause.Done witness. Native marker representations are private and must never reach generic emission. A direct flatMap consumes make into QueueScope; owner handles cannot escape through expressions, results, composites, callbacks or delayed resource finalizers. Inline ensuring may borrow a still-enclosing owner.
- **QIR-002 — Preserve terminal typing.** Default error remains Never, matching upstream. An explicit Done witness is required for end and take can then fail with Done. Schema validates Cause.isDone plus undefined completion value. Do not encode Done as Unit, Option.None or Bool. Interruptions remain Effect interruption, not successful false from take; blocked offer shutdown returns successful false. Rich errors/fail/failCause and parameterized Done remain separate gates.
- **QIR-003 — Narrow upstream-shaped builders.** Source-private QueueIR.make takes a payload witness, positive literal capacity/suspend options and optional error witness; bounded takes payload witness then capacity and optional error witness. Both allocate the same QueueMake node. offer is dual(data-first/data-last); take/end/shutdown are unary. Restrict capacity to1..3 for this workload rather than accidentally admitting arbitrary/rendezvous storage. QueueOperation distinguishes Offer with payload from Take/End/Shutdown without payload. Make/Scope retain capacity, payload and error witnesses; Scope additionally carries binder/body. take/offer are asynchronous even when immediate; native selection remains refused for every Queue graph.
- **QIR-004 — Official reference, not another scheduler.** Both ordinary and framed evaluators construct official Queue.bounded and invoke official operations. Each invocation creates fresh owner state. Queue scopes/operations participate in substitution, provenance, scope/task analysis, effect derivation and interruption-frame traversal. Mixed coordinator profiles must fail closed explicitly. No public exports, owned QueueExecution or native driver selection yet; generic lower and public Compile return a structured Queue refusal.
- **QIR-005 — Compiler escape and counterfeit audit.** Validate capacity and channel witnesses even on manually constructed nodes; match binder's exact owner channels. Offer expression witness must match the owner payload. Enforce operation output/error channels and end's Done capability. Pure native paths reject handles and private Done markers. Check that registered cleanup cannot retain the Queue lifetime; unsupported programs must fail before generating Rust.
- **QIR-006 — Admission evidence.** Test ordinary/framed official success and Done/interruption, fresh state, lexical substitution, source paths, authoring type contracts, malformed nodes, escape/cleanup checks, and native/mixed-profile refusals. Compare controlled producer/consumer and shutdown/cancellation traces where representable. Never-error All workloads and simple child Done recovery use the official reference. Changing Done after a fallible task group or asynchronous cleanup remains refused by retained-outcome analysis; those are separate ownership/representation gates. Keep the independent protocol debug/release suite. Generated producer-before-consumer continuation, Drop routing, operation budgets, future/layout costs and public admission remain subsequent gates.

## Recovery refinement — QIR-007

Before refinement, conservative retained-failure analysis marked every Queue operation and owner as a possible suspension after selecting failure, refusing even sequential catchAll on Done. Queue offer/take suspension precedes completion; QueueScope introduces no resource finalization. Therefore QueueMake/QueueOperation alone do not retain a selected typed failure across suspension, and QueueScope recurses into its body, like lexical Ref. Task groups, resource Scope and asynchronous finalizers remain risky; Done recovery crossing those boundaries remains refused pending richer retained-outcome ownership/representation. This only enables official private reference recovery; every native Queue graph remains refused.

## Version boundary

The duplicate [issue8871](https://github.com/Effect-TS/effect/issues/8871) is closed. Do not file another report for an already-fixed bug. This work does not upgrade Effect; baseline migration requires its own scheduler/schema/profile audit.
