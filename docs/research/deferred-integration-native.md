Prepared 2026-10-04 before source edits against Effect 4.0.0 and Tokio 1.53.1. Reviewed PLAN, PROGRESS, AGENTS, inline owner DS-001–005, semantic turns TURN-001–012 and the actual AsyncContext / task-group lowerer. Online primary sources: [Deferred 4.0.0 source](https://unpkg.com/effect@4.0.0/src/Deferred.ts), especially `doneUnsafe` and await cleanup; [Tokio unconstrained](https://raw.githubusercontent.com/tokio-rs/tokio/tokio-1.53.1/tokio/src/task/coop/unconstrained.rs). This record supplements the core/budget agents' integration preparation.

## Decisions before implementation

- **DIN-001 — Prove the actual context adapter first.** Introduce a private, unselected runtime emitter combining the existing owner and turn bank with the real generated AsyncContext. A borrowed `DeferredTurnHandle` contains only a bank reference and checked task slot; AsyncContext remains lifetime-free. Native scalars carry no coordinator tag or metadata. Lowerer/public admission waits for ownership, callback-budget and independent-cancellation checks.
- **DIN-002 — Mask the entire completion broadcast.** Check ambient interruption before entry, save the context mask, disable interruption while the completion adapter visits the detached cohort, restore the old mask, then check interruption before exposing the Boolean to authored continuation. This preserves synchronous upstream broadcast even when a callback interrupts its producer. An already-masked producer receives its Boolean and observes interruption only after outer restoration. Future Drop/panic while an armed broadcast is incomplete remains unsupported, as for other cooperative native cleanup.
- **DIN-003 — Ack only task completion or known semantic suspension.** Wrap explicit primitives, not every helper future. Deferred wait and timer/watch suspension mark the task; completion's artificial Pending does not. Wrap primitive polling in Tokio `unconstrained` to prevent its cooperative scheduler budget from creating a Pending that would be misclassified as an Effect suspension. The separate audited Effect operation-budget gate remains required; disabling Tokio's cooperative budget does not establish that gate.
- **DIN-004 — Static fixed polling, safe pinning.** Prototype All2/3 with caller-supplied distinct checked slots, inline pinned child futures and inline result slots. Restart polling only when bank priority changes; bound adapter retries per executor poll and wake when exhausted. No raw future pointers, Box, Arc, global/TLS registry or stored per-waiter Waker. First prototype is a join/coordinator kernel; it does not pretend to implement fallible All semantics or Race winner cancellation.
- **DIN-005 — Preserve existing emitters.** Compiler-selected runtime and public source remain unchanged while these helpers are unreferenced. The source adapter will need build-owned helper capacity/task arguments, richer retained-failure reachability, fixed routes, true primitive marking, and finalizer ordering before actual lowering. Nested initial Race, independently canceled waiters and typed compound Cause remain explicit admission gates.

## Acceptance

Compile the private emitter with the existing real AsyncContext and exact pinned Tokio in debug and release. Compare producer interruption/masking traces with independently authored official Effect; check waiter interruption removes its registration and runs its synchronous cleanup prefix before producer continuation. Awaited cleanup needs a separate finalization signal to establish completion. Exercise typed retained outcomes, losing completion and late await, real timer suspension, repeated task slot reuse and independent owners. Report adapter layouts separately from heap costs; no complete allocation or None/Bounded claim follows from an isolated prototype.

## Completed private context/coordinator slice

`deferred-coordinator-runtime.ts` now emits the borrowed handle, actual AsyncContext await/completion/timer adapters and pinned fixed join2/join3 driver. It is unreferenced by compiler/public exports. Direct `lowerFunctions` traversal refuses every new Deferred IR node with `DEFERRED_NATIVE_INTEGRATION`; the compiler's separate plan gate remains the primary public refusal. The private joins validate distinct in-range task IDs, at most four bank slots, and no callback-time group startup; they are coordinator experiments rather than fallible All or Race implementations.

`deferred-coordinator-runtime.test.ts` runs exact pinned Tokio 1.53.1 with the existing generated AsyncContext. Debug and release outputs match. Five independently authored official Effect traces match in ten fresh-owner repetitions each: reversed registration, waiter yield, interrupt next waiter, interrupt producer, and interrupt masked producer. Additional typed u64 failure delivery/late await, losing completion, empty-owner rejection under already-present cancellation and cleared registrations/turns pass. Producer cleanup uses real awaited Tokio timers under the restored/masked actual context. Measured borrowed handle is **16 bytes**, baseline unchanged AsyncContext **24 bytes** on Rust 1.98.1 Linux x86_64; no coordinator allocation or full None/Bounded cost claim was measured here.

Validation command: `CARGO_PROFILE_DEV_DEBUG=0 CARGO_INCREMENTAL=0 ./node_modules/.bin/vp test packages/reffect/tests/deferred-coordinator-runtime.test.ts --maxWorkers=1` after sourcing the Rust environment: **1/1 passed**, 20.39 s total, both Rust optimization modes. Strict workspace TypeScript passed after the new-node lower handlers were added. Root will perform the merged checks and post-commit review.

A differential failure during development caught a fixture mismatch: adding an awaited timer to native canceled-waiter cleanup while keeping the official cleanup synchronous legitimately lets the producer continue before cleanup finishes. The fixture now matches the official synchronous cleanup. This reinforces DIN-003: a callback's actual cleanup suspension acknowledges its synchronous prefix, rather than holding the broadcast until all asynchronous finalization finishes. The independent-cancellation acceptance workload therefore needs a separate finalization signal; broadcast alone cannot prove cleanup has completed.

Remaining gates: actual helper capture/capacity lowering; global callback-budget admission; nested static Race routing and independent waiter cancellation/finalization; retained richer Cause behavior inside the admitted topology; frame-policy differential traces and total invocation/future/heap costs. Runtime asserts are checked-profile invariants, not untrusted-input validation. Forced host Drop or panic while masked completion is active still abandons the cooperative cohort.

The [generated lowering slice](deferred-generated-lowering.md) now supplies private checked owner/helper captures and All2/3 routing for the narrower zero-input, Never-error profile. Its [conformance/cost record](deferred-generated-conformance.md) verifies actual emitted helpers and records invocation layouts/allocations. The broader gates above still apply before public admission, especially executable default-context enforcement, nested cancellation and richer outcomes.
