# Private Deferred interruption frames — 2026-10-05

## Preparation and verified sources

Read the current roadmap and progress, the [Deferred execution boundary](deferred-execution-boundary.md), [operation budget](deferred-budget.md), [nested conformance](deferred-nested-conformance.md), and the existing framed reference interpreter, private lowerer and bounded trail runtime. This slice closes a diagnostic parity gap in the already checked private Deferred profile. It does not admit public Deferred, richer error channels, arbitrary contexts or additional topology.

The installed **Effect 4.0.0** source was checked online against the published package; the following files match byte for byte:

- [Cause.ts](https://unpkg.com/effect@4.0.0/src/Cause.ts): `Cause.map` maps only typed Fail payloads; Interrupt and Die reasons survive unchanged.
- [internal/core.ts](https://unpkg.com/effect@4.0.0/src/internal/core.ts): Failure evaluation skips ordinary failure continuations while an interruptible fiber has a pending external interruption (`Failure` evaluation, around lines 548–550).
- [internal/effect.ts](https://unpkg.com/effect@4.0.0/src/internal/effect.ts): `OnExitImpl` masks finalizer execution through its `contAll` hook; `onExit`, `ensuring`, `Exit`, `setInterruptible`, `runPromiseExitWith` and terminal fiber observation establish the lifetime contract.
- [Deferred.ts](https://unpkg.com/effect@4.0.0/src/Deferred.ts): the independent oracle remains official Deferred, including registered waiter suspension and completion.

A direct installed-package probe confirms that `Effect.never.pipe(Effect.catchCause(...))` does not invoke that handler after external AbortSignal interruption. Likewise, `Effect.never.pipe(Effect.exit, Effect.map(...))` never invokes the map callback; its outer terminal Exit is interrupted. Existing framed interpretation therefore cannot finish constructing its normal result after external cancellation. The existing nested suite compares interruption/logs and only checks that native bounded frames are nonempty; it does not compare exact interrupted reference/native trails.

## Decisions

**DINT-001 — Preserve actual semantic interruption.** Do not turn an Interrupt into a typed Fail merely to reuse `FramedDomain`. Do not infer interruption from an AbortSignal once computation has succeeded. Await the real root terminal Exit, preserving its Cause and completed finalization, then construct the observation. Existing composable research interpreters retain their behavior; the new cancellation observation belongs to the private standalone Promise boundary.

**DINT-002 — Observe with `onExit`, not `catchCause`.** Extend the existing framed interpreter privately with an optional per-invocation recorder and linked root-boundary cursor. Each observed evaluator carries its boundary and parent cursor. The first `onExit` callback observing a genuine interrupted Exit records that cursor's complete innermost-first chain, including the function boundary, retaining 32 frames and counting the omitted suffix. It synchronously updates the recorder and returns fixed `Effect.void`; official finalizer masking allows it to observe interruption where ordinary continuations are skipped. Outer observers cannot replace a captured inner trail. This is diagnostic JavaScript state, outside scalar/domain payloads and independent of native representations. It must never expose a caller callback, raw Fiber, custom context, or global recorder. Independent invocations cannot overwrite each other. Calls without the private recorder retain the existing interpreter behavior.

**DINT-003 — Retain the native group boundary policy.** The current infallible native All/Race adapter deliberately discards child interruption trails and starts the parent failure trail at its `all` or `race` boundary. Match that contract rather than guessing which concurrently canceled child supplies the logical stack. Pass no private cursor into task-child or finalizer evaluation. A canceled losing Race child must not leak a trail into a successful parent. On parent interruption, the group's observer records its own boundary and enclosing root cursor chain. A root Await or Sleep records its own leaf and enclosing Map/FlatMap/Match/DeferredScope/Ensuring boundaries. Finalizer diagnostics cannot replace the suspended body trail.

**DINT-004 — Observe after cleanup, and distinguish no execution.** The standalone runner reads the recorder only after `runPromiseExitWith` settles, so masked asynchronous finalizers have completed before observations become visible. For started in-flight interruption, private `runWithFrames` returns an outer successful observation containing an interrupted `FramedExit`, using the actual terminal root Cause. Plain `run` retains its terminal interrupted Exit. A valid pre-aborted invocation still starts no source computation, emits no logs and fabricates no frames, as specified by DEXEC-004; its outer Exit remains interrupted. This host-level refusal to start differs from manually invoking a generated native function with an already canceled context, which currently records its function boundary. Those are different entry contracts and must be tested explicitly.

**DINT-005 — Reaudit framed operation receipts.** `onExit` adds evaluator work even to successful execution. Existing DBUD receipts cover ordinary decoration and cannot silently cover the new observers. Plain interpretation and its receipts remain unchanged. Charge each installed private diagnostic observer separately; an additional **20 framed operations per observer** is a deliberately conservative candidate bound, subject to corroborating scheduler probes and the receipt below. Apply it only to the private observed path; exclude child/finalizer paths when their observer is absent. The private admission checker uses the resulting observed bound before starting any fiber; future public admission must carry this contract explicitly. Boundary cases must continue to refuse at 2048 with automatic yielding enabled.

## Candidate observer receipt

The callback performs bounded synchronous JavaScript work and returns only `Effect.void`. It invokes no Effect-valued caller code. In the published `OnExitImpl` source, success evaluates the OnExit wrapper, the returned finalizer FlatMap, the fixed finalizer Success and the retained exit. Failure adds `combineFinalizerCause`'s OnFailure wrapper and a possible combined failure; restoring interruptibility can inject an additional pending-interruption failure. Conservatively sum these incompatible routes and allow additional terminal failure and continuation-return slots: 20 operations covers one observer, including the OnExit primitive, fixed callback result, combination/retention and restoration. The callback itself and stack scanning are synchronous JavaScript, not evaluator primitives. Authored body/finalizer Effects are accounted separately by their existing receipts. An additional root observer, if installed, needs its own charge; do not hide it in node weights. Exact implementation placement determines the final receipt and must be recorded with validation.

Alternative approaches were rejected: `catchCause` skips external interruption; replacing Interrupt with Fail changes Cause semantics; disabling interruption or scheduler yielding changes the admitted profile; an ambient global/Context recorder permits cross-invocation interference or caller injection; reconstructing the trail from a canceled signal or graph walk reports unexecuted branches. Native child frames are already discarded by the supported group adapter, so changing native aggregation would expand this slice unnecessarily.

## Occurrence and API boundaries

The existing framed reference uses first-seen `Computation` identity paths. Native helper memoization keys computation **node**, incoming lexical Scope and error channel. Task children create distinct incoming scopes; source wrappers can share a node while having different computation identity. These are not a general occurrence-path equivalence proof. Keep this limitation explicit, test admitted shared root paths, and refuse or resolve unsupported sharing rather than inventing child frames. The internal reference already accepts a `basePath`; exact tests should pass the same `functions.<export>.body` used by lowering. The standalone fn-only runner has no public export name, so its default path is an observation convention rather than an emitted-program path.

## Refinements from implementation review

**DINT-006 — Refuse ambiguous root sharing (superseded within the private observed profile by DINT-008).** The first exact probe exposes a real identity mismatch: source wrappers sharing a node can acquire separate reference paths but one native helper path; lexical scope changes can produce the reverse. The observed private entry rejects any repeated computation node involving its root diagnostic spine with `DEFERRED_FRAME_SHARING`. Scan task children and finalizers too: although their frames are discarded, their first visits seed the existing reference path table. Child-only sharing remains allowed. A later scope-indexed canonical path resolver can remove this conservative refusal; existing ordinary reference/native sharing is unchanged. Internal recorders are single-use across actual executions, including rerunning the same constructed Effect.

**DINT-007 — Explicit private generated query limit.** Privately admitted 34- and 40-Map asynchronous Await chains both fail rustc's default query-depth limit while computing future layout (the reported exhausted query depth is 130). The [Rust Reference](https://doc.rust-lang.org/reference/attributes/limits.html#the-recursion_limit-attribute) documents the crate recursion limit and its default of 128; checked online before changing emission. Emit `#![recursion_limit = "256"]` in both actual private Deferred library and generated entry crates. The allowance is crate-local: a custom harness copies the emitted entry attribute, and custom Rust consumers must set their own finite allowance for exposed deeply nested futures. This tests the generated configuration rather than inventing a test-only library limit. Keep it finite and test the 40-Map native truncation witness (43 boundaries, 32 retained and eleven omitted) in debug/release and both frame policies. This is a compiler query allowance, not heap allocation or an ABI change. It does not prove all admitted graphs compile: generated async nesting/query-depth admission and whole-graph growth remain open before public Deferred. Ordinary emitted crates, scalar/context layout and native runtime are unchanged.

Implementation charges 20 additional framed operations only on the monitored root spine; concurrency children and Ensuring finalizers keep ordinary receipts. Memoized summaries distinguish monitored and ordinary paths, while repeated graph edges retain occurrence cost. The standalone fn-only observation uses `functions.work.body`, matching its internal checked program name; program-specific research/native comparisons pass explicit matching export paths.

## Shared-path preparation — 2026-10-05

Rechecked the current private admission, reference adaptation and native helper memoization before implementation. The pinned [Effect 4.0.0 core source](https://github.com/Effect-TS/effect/blob/effect%404.0.0/packages/effect/src/internal/core.ts) was downloaded again and matches the installed source byte for byte. Official interruption/finalization semantics remain unchanged; canonical IR paths are the compiler's diagnostic convention, not Effect runtime stack locations.

**DINT-008 — Scope-indexed private diagnostic plan.** Replace DINT-006's conservative sharing refusal only for the already admitted private profile. Build a per-invocation static plan keyed by computation node and incoming lexical scope. Every admitted computation has the same Never error witness, so the native memo's third (error-channel) dimension is constant here. Record first-seen helper paths and child-edge references in native traversal order. DeferredScope bodies, FlatMap bodies and each TaskGroup child introduce fresh scope identities; Map sources, Match branches and both Ensuring edges preserve incoming scope. Tagged Match cases introduce fresh scopes. A source wrapper does not introduce a new identity. Memoized parents retain their original outgoing edges; a second occurrence must not recursively create new child scopes.

The monitored interpreter follows explicit child edges through this plan. This avoids runtime value/binding-based scope guesses and distinguishes FlatMap source/body edges even when both point to one node. Traverse finalizers and task children while preparing the plan, but install observers only on the existing root diagnostic spine. A finalizer-first node later used in the same root scope keeps its finalizer path; a task-child-first node later used by the root gets the root path because its scopes differ. Retain first-executed boundary capture, single-use invocation ownership, 32-frame truncation and ordinary unmonitored interpreter behavior.

Alternatives: globally keying by node fixes source wrappers but still merges distinct scopes; assigning every use-site path disagrees with native helper reuse; deriving paths by invoking the Rust lowerer couples reference execution to backend operation selection and would weaken differential evidence. The chosen plan models only the checked private subset and explicitly refuses unhandled nodes. It adds invocation-owned JavaScript planning data, with no native payload/context fields or new Effect primitives; the existing observer receipt remains applicable. General graph-growth admission and public exposure remain separate gates.

Independent review identifies a separate planning-cost risk: execution receipts take maximum branch costs, while fresh lexical scopes can expand a compact shared graph into many helper entries. Cap this private diagnostic plan at **4096 entries**, counting each distinct node/scope pair before allocating it. Prepare after existing profile checks but before source execution; return typed `DEFERRED_FRAME_GROWTH` on overflow. This provisional diagnostic bound is distinct from the 2048 evaluator-operation bound and the existing 512 IR nesting limit. It does not establish native compiler query-depth or invocation/future-size admission. A compact shared branching fixture must pass execution admission yet refuse diagnostic planning without emitting its leading log.

Acceptance: topology-authored exact trails for shared source wrappers, FlatMap source/body reuse, shared Match parents, child-first/root reuse and finalizer-first/root reuse. Compare actual native None/Bounded in debug/release with private standalone observations and independently authored Effect Cause/cleanup behavior. Include successful shared execution, collector reuse refusal, unchanged budget/context checks and ordinary frame regressions. Independent review must verify lexical transitions against native lowering rather than reading expected paths from either implementation.
