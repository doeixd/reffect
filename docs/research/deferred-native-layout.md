# Private Deferred native layout admission

Prepared 2026-10-05 before feature implementation. Synced through a8409f6 and installed dependencies, preserving the separately owned records/Remote/PLAN work. Reviewed DGROW-001–005, NSTORE/NFL, capture pruning, native root emission, owned standalone execution and Cargo diagnostics. Structural receipts reject known expansion/query failures; they do not know the target's concrete future layout.

## Primary sources and research

Checked installed Rust **1.98.1**, Tokio **1.53.1** and Effect **4.0.0** against the Rust Reference [const blocks](https://doc.rust-lang.org/reference/expressions/block-expr.html#const-blocks), [async function capture](https://doc.rust-lang.org/reference/items/functions.html#async-functions) and [`size_of`](https://doc.rust-lang.org/std/mem/fn.size_of.html). Inline const blocks can reference generic types. An executed const expression must be evaluated at compile time; a dead witness need not be evaluated. Layout includes padding and may change between compilations. Async function arguments are captured for drop ordering; the current private profile has zero authored inputs and an always-used borrowed context.

A standalone research probe passes an exact 20480-byte Future and rejects 20481 bytes with **E0080 / REFFECT_DEFERRED_FUTURE_LAYOUT** under debug and optimized Rust. Metadata-only `--emit=metadata` accepts the oversized instantiation: type checking alone is not this admission gate.

An actual emitted, structurally admitted workload is larger than the existing fixture budget: outer All3 containing an initial Race2 (40-Map Await versus Unit) and two further 40-Map waiters on the same owner. Its framed evaluator receipt is **1136**, weighted depth is 50, and the unchanged Bounded/debug exported future measures **21136 bytes** on x86-64. It is intentionally pending; research constructs and drops it without polling. The temporary research test is removed. This is a real authored graph witness, rather than a source mutation that inserts an arbitrary padding field.

## Decisions before implementation

**NLAY-001 — Enforce a target-specific inline future ceiling at native code generation.** Reuse NSTORE-004's **2560 × sizeof(usize)** budget for every private Deferred root future. On the current x86-64 target this is 20480 bytes. It is an explicit conservative private performance policy, not a portable ABI claim or a universal Effect limit. The assertion reruns with the concrete type on each target/compiler build. Structural/query, module/text and emitted-source ceilings continue to apply independently.

**NLAY-002 — Measure the exact returned root future by reference.** Emit a private generic helper returning `usize` from a value-bearing inline const that asserts `size_of::<F>() <= 2560 * size_of::<usize>()` with message `REFFECT_DEFERRED_FUTURE_LAYOUT`, then returns the checked size. For private Deferred exports only, emit a synchronous `pub fn` returning `impl Future<Output = ...> + '_`; construct the entire original body as an `async move` block, borrow that future for the assertion, then return the same future. This adds no Future wrapper, fields, Box, dependency, runtime size branch or large by-value helper argument. Ordinary synchronous/async exports keep their existing form. The edition-2021 explicit return lifetime retains the context borrow.

Native validation identifies a release-only flaw in the initial unit-valued borrowed helper: an unused exported constructor can compile after its unit const statement is erased. A standalone `rustc -O --crate-type=lib` probe reproduces this. Before correcting implementation, revise the helper to return `usize` from `const { assert!(...); size_of::<F>() }`, then bind the returned constant to an unused named local (`let _layout = ...`) at the call. Actual release-library testing also erases a bare discarded call, whereas the standalone value probe binds its result; the actual emitter must match the tested binding form. The value-bearing constant is evaluated during this toolchain's optimized monomorphization; the same standalone uncalled export now fails E0080. Both build profiles and uncalled library constructors must remain regression witnesses. This adds no retained size field or runtime size branch, and reinforces that future compiler drift needs validation rather than a timeless optimizer guarantee.

**NLAY-003 — Preserve lazy construction and provenance.** Keep frame reset, cancellation checking, bank/owner construction and authored work inside the async block. Constructing or dropping an unpolled future must not execute logs/finalizers, clear diagnostic state or allocate owner state. Existing helpers and scheduling remain unchanged. Compose the original mapped body fragments with the new wrapper and attribute the assertion call to its function; do not transform already emitted strings or lose byte ranges. Continue to use existing CargoError/NativeDiagnostic reporting; E0080 with a distinctive layout message is a build diagnostic, not a JavaScript CompileError or a portable layout receipt.

**NLAY-004 — Be precise about the boundary.** A native code-generating build checks the concrete instantiated future; `cargo check`, generic metadata, source emission, and standalone official-Effect execution do not establish native layout admission. Verify current `cargo build --lib` behavior for an uncalled exported private root as well as actual executable construction. Do not rely on a dead synthetic witness as the implementation. Public Deferred remains refused. Only the root's inline storage is bounded: referenced AsyncContext, allocations, peak construction stack and compiler heap remain separate budgets. Wider inputs would need a fresh async-capture/drop-order assessment.

Alternatives: checking only a helper misses bank/owner/root adaptation; a by-value identity helper can add transient moves in debug; a boxed adapter changes the desired inline representation; inferred byte formulas cannot account for compiler layout; running a native executable adds a target execution dependency; an unused witness is not a guaranteed const-evaluation boundary. Borrowing an unconditional exact-root check preserves the current representation and works on the stable compiler.

**NLAY-005 — Force native layout code generation without slowing constructors.** Actual native testing finds a second optimizer boundary: even the correct named value binding in an uncalled anonymous-future constructor can be deferred by release cross-crate inlining. The real None future remains **21072 bytes in both debug/release**; the acceptance is not a smaller layout. Independently checked pinned [Rust 1.98.1 cross-crate inlining source](https://github.com/rust-lang/rust/blob/1.98.1/compiler/rustc_mir_transform/src/cross_crate_inline.rs) explicitly documents `#[inline(never)]` as forcing code generation. Applying it to every root would affect ordinary constructor calls and possible temporary moves. Instead emit one `#[doc(hidden)] #[inline(never)] pub fn reffect_deferred_future_layouts(ctx: &mut AsyncContext) -> [usize; N]` for the private crate. Each separate element scope constructs one real root, returns its checked constant size and drops the unpolled future before the next context borrow. Its concrete non-Future return and annotation force the current compiler to evaluate all root checks. Mains/ordinary invocation never call the report. It adds one cold generated symbol and a fixed-size array return ABI, not a context/scalar/future field, heap allocation or runtime invocation check. It may be removed at final binary linking; do not claim a universal linker-size guarantee. Keep uncalled library and optimized excess tests permanently. Public build-receipt/tooling integration remains future work.

Preparation measurements of guard-free constructor variants confirm target-specific boundaries: None futures with (unused prefix owners, Map depth) (0,40), (8,32), (24,16), (38,0) measure 21072, 20688, 19920 and 18608 bytes respectively, identical in debug/release. The temporary variant test is removed. The selected first graph is a real native overflow under both frame policies, not an optimizer-dependent byte prediction.

## Acceptance

- The real All3/Race2 graph passes private JavaScript structural/budget checking but fails native code generation with the layout diagnostic, including an uncalled library export, debug/release and None/Bounded policies.
- Exact inclusive layout boundaries pass/refuse using concrete Future types and the emitted checker; metadata-only checking is explicitly not sufficient.
- Previously admitted native boundary/nested/cancellation/truncation workloads retain their outcomes and frame trails across policies/build profiles.
- Construction and unpolled drop remain inert; quiet invocation allocation and capture budgets remain intact.
- Source artifacts retain valid mapped body/call ranges, ordinary exports omit the guard, and disabled metadata/frame policies do not bypass layout limits.

Remaining work: public owned-context admission, richer outcomes/captures, target/compiler drift coverage, native build receipts for tooling, referenced/retained heap and peak compiler/construction memory. This delivers a concrete native build-time ceiling, not all performance gates.

## Delivered evidence

The sequential actual native sweep passes **25/25 across five suites (360.06s)**: new layout admission, prior generated-growth boundaries, nested coordination, exact interruption trails and helper capture costs. The exact 2560-pointer synthetic future passes, while one extra byte fails E0080. The real All3/Race2 root refuses in debug/release under None/Bounded even when its export is uncalled and only the library is built. Disabling the single shared const assertion makes that same emitted workload build, proving the failure is the layout policy rather than unsupported source. Metadata-only Cargo checking still accepts it and is explicitly insufficient.

The new native fixture compiles two aliased exports, exercising separate context borrows in the cold report. Four frame/build variants confirm allocation-free future construction, inert unpolled drop with preserved sentinel frames, pre-aborted work remaining unopened, and exactly one active source/cleanup trace. A fresh context is used after cancellation because cancellation is latched per invocation. Existing quiet tests retain zero allocations across **2800 metered invocations**. Nested cancellation/finalizer ordering and exact bounded interrupted trails remain unchanged.

New constructor boundary measurements (None/Bounded) are **2696/2696**, **848/896** and **12440/12488** bytes for depth, branching and weighted group workloads, identical in debug/release. The eight-byte changes in the observed Bounded layouts follow the constructor form; these are compiler observations, not an ABI or portable reduction promise. The root ceiling remains separate from referenced context/heap and peak stack/compiler memory.

Focused JavaScript checks pass **28/28 across six suites (7.61s; four native tests excluded)**, covering ownership/context budgets, public refusal, real private structural admission, UTF-8 body/call mappings and runtime-source parity. Full check passes **472 formatted files / 288 TypeScript files** without warnings/errors; strict package TypeScript and rebuilt workspace pass (one package rebuilt, three cache hits). Independent review confirms report scoping, constructor laziness, exact future identity, provenance and the explicit native-build boundary; its Unicode coverage and array-ABI wording findings are addressed. Post-commit checks follow before publication.
