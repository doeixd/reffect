# Queue terminal control foundation

Prepared 2026-10-07 before implementation against PLAN/PROGRESS, QPUB, QIR, QBF, QINT, QASYNC and existing bounded/borrowed/generated Queue sources. This is the next private completion prerequisite; public offer/take admission remains unchanged.

## Primary evidence

Fresh published [Effect 4.0.0 Queue.ts](https://unpkg.com/effect@4.0.0/src/Queue.ts) has SHA-256 `6781fd0ac6fad03057ebeaa838d0f9723913027a4f6845d57dc3c17da70d1953`, matching prior and installed evidence. `end` delegates to `failCause(Done())`; Closing retains buffered and registered offers and refuses new offers. `shutdownUnsafe` clears buffered messages, preserves an existing Closing terminal, resumes terminal takers before pending producers return false, and returns false after Done. Take observes owner Done as typed failure, while owner interruption and fiber control interruption remain distinct.

Ordinary controlled terminal workloads below avoid that defective topology.

## Decisions before implementation

- **QTERM-001 — Preserve three channels.** Existing QueueTerminal Done/Interrupted describes owner completion. QueueInterrupted describes cancellation of the requesting child. Add private `end_exit` and `shutdown_exit` returning `Result<bool, QueueInterrupted>`, just like offer_exit. Do not encode child cancellation as false or owner Done as interruption. Reuse the same request phase/generation/ticket protocol; no new runtime fields or payload wrappers.
- **QTERM-002 — Keep ordinary cancellation separate from cleanup masking.** Ordinary terminal helpers use the sticky child-interruption gate. Cancellation must prevent posting a terminal operation and leave owner lifecycle/buffer unchanged. Existing `cleanup_shutdown` remains the explicitly masked finalizer helper. Keep the old non-cancellable research convenience methods for existing fixtures; they do not establish generated cancellation semantics.
- **QTERM-003 — Reuse synchronous terminal routing.** End/shutdown still execute through the driver, settle selected peer continuations before the initiating operation returns, and retire registrations normally. A peer can recover Done locally and complete normally; later parent interruption cannot revoke completed children. Closing shutdown must retain Done; Open shutdown must retain interruption. Repeated terminal operations return false. Test these behaviors against official public Effect, not hard-coded native expectations alone.
- **QTERM-004 — Stage generated/public admission.** Do not widen queue-generated-profile, QueuePublic, compiler marker audits, or NativeRpc. Next design an explicit native unit Done carrier and local catchAll representation, then prove retained/fail-fast outcomes across All, frames/default2048 receipts, generated cleanup/masking and actual layouts. Done must not silently become Unit/Option/Bool or a user payload. The existing error witness remains private until its representation and exports have those gates.
- **QTERM-005 — Acceptance and costs.** Compare controlled End drain/empty waiter/Closing shutdown/Open shutdown/repeated terminal traces in debug and release. Probe actual driver interruption followed by rejected ordinary End/shutdown, and explicitly masked cleanup shutdown, including owner state and absence of posted requests. Negative mutations must distinguish cancellation false, lost Closing Done and delayed peer completion. Measure quiet execution allocations and actual terminal child future layouts; keep public/generated conformance serial. Raw borrowed-driver probes do not prove host-future Drop, RPC/Send, full Cause identity or generated costs.

## Alternatives and remaining gates

Exporting private End/shutdown immediately would bypass typed terminal representation and pinned scheduler/topology constraints. Mapping all QueueTake::Terminal values to AsyncError::Interrupted is valid only for the current Never/end-free public profile and must change before Done admission. Adding another queue implementation or heap-backed typed envelope is unnecessary for this control prerequisite. The existing inline enum plus control Result preserves the distinction without adding per-message storage.

The first delivery is cancellable private terminal helpers and differential evidence. Public End/Done, retained failures/fail-fast, generated terminal frames/budgets, finalizers/timers, request hosting and broader strategies remain open. PLAN.md belongs to the core instance and is unchanged.

## Delivered private extension

The two terminal control helpers reuse QueueRequestFuture without new owner/bridge fields or payload metadata. Tests compare four terminal trace families with official pinned Effect and probe cancellation and masked cleanup separately. Completed peers cannot be interrupted again. Four deliberate negative mutations fail the relevant trace/control contracts. No public Queue surface, compiler profile or native error representation changes.
