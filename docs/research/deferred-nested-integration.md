# Private nested Deferred integration

Prepared 2026-10-05 before integration edits. Reviewed DOWN-004–006, DGEN/DGR, capture costs, the current checker/reference wrappers, topology summaries and static routing. Checked the installed Effect 4.0.0 `raceAll` and published [internal source](https://unpkg.com/effect@4.0.0/src/internal/effect.ts): eager children start in input order, successful completion stops further startup, and the exit handler interrupts and awaits losers. Tokio 1.53.1 remains the substrate.

**DNI-001 — Narrow private topology.** Extend only the checked private generated profile to an outer All2/3 with an initial inner Race2 and at most six contexts. Nested All, deeper groups, root Race, compound outcomes, callback startup after Deferred Await/Complete and groups in cleanup remain refused. Relative per-node capacities stay compiler-owned; each occurrence reserves distinct contiguous identities, with reuse after complete retirement. Public compiler and ordinary reference admission remain unchanged.

**DNI-002 — Share reference evaluation, keep checking private.** Add internal checker injection to the existing plain/framed evaluator implementations. Public reference wrappers expose their original arguments and always select ordinary checking. A separate module-private package entry validates the complete generated profile before invoking those same interpreters. It adds no new Effect wrapper/scheduler operation to successful evaluation, preserving the audited default-context operation budget. No public safety assertion or export admits nested groups.

**DNI-003 — Completion, cancellation and retirement are separate.** Route priority through static descendant ranges. Inner drivers may consume global progress flags, so parent drivers also compare priority before/after child polling. Race returns success only after a winning child and complete loser cleanup; a canceled loser is not a failed race. Synchronous winners skip unstarted children. Group-owned registrations/requests must retire before route reuse; an active ancestor request may legitimately survive inner completion.

**DNI-004 — Validate actual emitted code.** Require independent official/private plain/private framed/generated traces for isolated waiter cancellation, a surviving waiter, retained/losing completion, cleanup signals and parent cancellation. Cover both producer positions and repeated fresh-owner route reuse. Compile debug/release with both frame policies; report nested future/context/driver costs separately from quiet zero-allocation baselines. Ordinary output, public refusal, provenance and existing capture-growth gates remain required. Exact interrupted diagnostic parity, richer outcomes, executable default-context enforcement and wider topology stay open.
