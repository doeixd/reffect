# Public bounded Deferred execution

Checked 2026-10-05 against installed `effect@4.0.0`, its `src/Deferred.ts`, and the [upstream Deferred source](https://github.com/Effect-TS/effect-smol/blob/main/packages/effect/src/Deferred.ts) fetched today. Installed source is authoritative for this release. Upstream `make`, `await`, `succeed`, and `isDone` establish one-shot broadcast completion; `succeed` supports data-first/data-last calls and reports whether it won completion. Full upstream failure/Cause completion is broader than the admitted native representation.

Prior decisions: [owned execution](deferred-execution-boundary.md), [context audit](deferred-context-audit.md), [generated profile](deferred-generated-lowering.md), [interruption frames](deferred-interruption-frames.md), [growth](deferred-generated-growth.md), and [native layout](deferred-native-layout.md).

## Decisions

- DPUB-001: expose `R.Deferred.make`, `await`, `succeed`, and `isDone`, plus the named `DeferredIR` export containing that same supported surface. `make` takes the success IRType witness required by compilation. Keep typed `fail` and the optional error witness in the internal builder until richer outcomes have an admitted native adapter. Public lexical handles still cannot cross function input/output/error channels.
- DPUB-002: expose the existing `DeferredExecution.run` and `runWithFrames` Promise boundary and their option/observation types. Its checked zero-input scalar/Never profile owns a fresh official Effect context, scheduler, log capture, operation budget and cancellation signal. No Effect-valued public wrapper is needed: a wrapper would reintroduce ambient context and evaluator costs into the parity contract. Existing `Reference.run` remains the ordinary official interpreter; contextual execution does not establish this owned runner's native parity guarantee.
- DPUB-003: compiler admission must reuse the exact generated topology/budget/growth checks and owned runner's builtin type/operation identity audit, then select generated Deferred lowering. Removing only the old blanket plan refusal would admit unsupported graphs and custom expression callbacks. Ordinary non-Deferred functions keep their existing implementation selection.
- DPUB-004: public means an explicit bounded standalone profile, not general Deferred/Fiber/RPC interoperability. Supported completions are Bool/U64/Unit with Never errors; at most six live task contexts; outer All2/3 with the already verified initial inner Race2. Context injection, richer failures, callback-started task groups, deeper/multiple Race, and nested All remain refused. Public admission does not relax the existing structural/text/emission or code-generation layout ceilings. Rust build is required to prove the latter; `cargo check`, source emission and JS execution cannot do so.

## Acceptance

Public import-only authoring must type-check without casts; completion is first-wins, later completion false, all waiters observe the same result. Test public compiler emission/build and owned reference observations, interruption/finalization, and refusal of unsupported profiles. Existing private conformance, growth, capture and layout suites remain the semantic/performance regression evidence. Validate native suites sequentially and document the exact tests run. Referenced heap and compiler peak-memory budgets, broader scheduler contexts and richer outcomes remain follow-up work rather than claims of this public profile.
