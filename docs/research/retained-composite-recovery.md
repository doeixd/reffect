# Composite recovery without retained failures

Recorded 2026-10-04 before implementation. Reviewed [retained outcomes](retained-outcomes.md), the task-group analysis, generated helper cancellation checks, `AsyncContext`, and `NativeRemote.mutation`. Verified installed Effect **4.0.0** against the published [core](https://unpkg.com/effect@4.0.0/src/internal/core.ts) and [runtime](https://unpkg.com/effect@4.0.0/src/internal/effect.ts) sources on this date.

**RCREC-001 — Refine the composite refusal.** NativeRemote transforms `RemoteServerError` into its wire witness through typed `mapError`/CatchAll. Ordinary store operations make that source asynchronous, but their waits precede failure selection. Async alone therefore does not establish interruption-bypassed storage for an earlier composite failure. Narrow changed-error composite refusal and its cancellation guard together when no reachable construct can suspend with a selected failure. Keep scalar carrier selection, same-error guards and fallible-group channel-change refusals unchanged.

**RCREC-002 — Build-owned conservative proof.** Memoize an exhaustive source visitor. Async masked acquisition/release, awaited Ensuring finalizers, resource Scope/registration/file cleanup, task groups and private Deferred are risky. Composed sources inherit risk through all children, including recovery and branch edges. Cycles are risky. Ordinary unmasked Sleep, RemoteStore, Launch and other leaves cannot preserve a selected typed failure across their preceding suspension. Streams remain conservatively risky. This is a sufficient proof, not a maximal failure-path analysis; no runtime value or context acquires metadata.

**RCREC-003 — Recovery linearization.** `core.exitFailCause[evaluate]` selects the failure continuation synchronously through `getCont(contE)`. Default runtime cooperative yielding happens before primitive evaluation; an interrupt while yielding replaces the unevaluated computation with the interruption cause. It does not create a retained typed failure between selection and recovery. Generated helpers propagate ordinary errors within the same poll. A watch sender on another Rust thread may change between those instructions; omitting this specific recovery guard preserves the same-poll linearization rather than treating that external watch timing as a new semantic suspension. Handler entry still checks cancellation. Custom reentrant schedulers/tracers and new runtime nodes need separate analysis; this does not establish arbitrary-context scheduling equivalence.

Alternatives rejected: suppressing only the diagnostic leaves an inconsistent guard/carrier decision; adding boxed composite failures broadens representation unnecessarily; removing every async guard loses verified scalar and cleanup-retained outcomes.

Acceptance: ordinary composite store/timer-before-failure recovery compiles; composite awaited cleanup or masked acquisition remains refused; same-error composite and scalar guards remain selected; shared/cyclic and resource cases remain conservative. Restore existing Remote mutation suites and rerun retained-outcome conformance before publishing. This repair does not admit compound RPC wire causes, task-group composite recovery or public Deferred.

Implementation evidence: two added ordinary composite admission regressions fail under the old analysis, then pass with the narrow proof. Focused analysis, RPC host and fallible-admission tests pass 15/15. All five formerly refused Remote suites pass sequentially on the multi-thread runtime: acceptance 2/2, mutations 3/3, SQL mutations 6/6, SQL Live 3/3 and todo page 1/1. Root checking, strict TypeScript and builds pass. Retained-outcome native conformance is included in the post-commit review before publication.

**RCREC-004 — Preserve inner conservative carriers.** Post-commit review found that a source can contain scalar async recovery which selects rich outcomes even without awaited cleanup. An outer composite channel change must remain refused when those conservative inner guards can forward a tagged scalar cause; otherwise its composite recovery could decode the wrong payload kind. Treat scalar asynchronous CatchAll/Retry descendants as risky too. This preserves the existing carrier approximation instead of silently narrowing scalar behavior. A regression checks an inner U64-to-Struct recovery under outer Struct-to-Never recovery.
