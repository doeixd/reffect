# Native retained-outcome repair

Preparation recorded 2026-10-04 before implementation. Reviewed AGENTS, PLAN, PROGRESS, DOWN-001–003 and TURN-012–013, fallible-native FN-001–006, and existing lowerer/coordinator/carrier code. Checked pinned [Effect 4.0.0 internal implementation](https://unpkg.com/effect@4.0.0/src/internal/effect.ts) online: OnFailure/catchCause and setInterruptible restoration preserve pending interruption independently of declared error channels. Existing controlled ownership probes establish the exact scalar retained-failure observation; this repair uses those as conformance evidence rather than claiming Rust semantics from source names.

- **RON-001 — Build-owned outcome selection.** Consume the checker’s retained-outcome summary at lowering time. Attach flags to helper/function plans; keep authoring A/E and scalar representations unchanged. A Never-returning child can require the rich coordinator. No metadata is carried by user values or AsyncContext.
- **RON-002 — Cancellation-aware typed recovery.** On checked asynchronous typed CatchAll/Retry sources, check mask-aware `ctx.is_cancelled()` before typed recovery. Same-E failures retain their original Fail; changed-E scalar failures become the existing nongeneric RuntimeCause. Combined outcomes forward unchanged when cancellation bypasses recovery. Masked execution retains existing continuation behavior.
- **RON-003 — Bounded rich children.** Select TaskFailure-based fixed-arity coordination from the outcome summary, forward Combined from Never children, and preserve completion/finalization order. Current unnested two/three-child topology and non-failing cleanup retain the existing three-failure capacity. Nested groups remain refused; this work does not widen capacity or introduce Deferred admission.
- **RON-004 — Preserve ordinary specialization.** Programs outside the checked rich profile retain existing enum/carrier/coordinator emission. Composite changed-E retention is refused by analysis. Same-E composite root catches may use a cancellation guard without scalar erasure. Rich host paths remain gated until CLI/RPC adapters accept their retained payload protocol.

Alternatives rejected: trust declared Never (drops valid failures); force every program onto boxed/Vec causes (unnecessary allocation/layout cost); replace retained failure with Interrupted (changes observable cause); invoke a typed catch while cancellation is pending (violates Effect). Reuse existing RuntimeFailure, safe borrowed futures, watch cancellation and finalizer masks.

Acceptance: independent official/reference/native cancellation during awaited cleanup, root and declared-Never All/Race children, same/changing scalar error channels, Retry and masked recovery; None/Bounded frame policies and debug/release. Check old infallible artifacts remain free of RuntimeCause and compare existing fallible cost tests. Root coordinates host refusal and common documentation.

Implementation status: build-owned outcome flags now select the existing carrier and group wrapper; async typed CatchAll/Retry obey mask-aware cancellation guards. The 12-workload independent differential matrix passes debug/release under None/Bounded, including suppressed retry and masked acquisition recovery. Existing fallible conformance/cost tests pass without changes to scalar/context layout or the three-failure carrier.
