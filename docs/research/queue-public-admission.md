# Bounded public Queue admission

Prepared 2026-10-07 against AGENTS, PLAN/PROGRESS, QGEN/QBUD/QEXEC/QFRAME, shared owned cancellation and the Latch/Semaphore/Deferred public compiler routes. Public exposure reuses the verified private offer/take profile; it does not broaden Queue scheduling or ownership.

## Primary evidence

Published [Effect 4.0.0 Queue.ts](https://unpkg.com/effect@4.0.0/src/Queue.ts) and [internal/effect.ts](https://unpkg.com/effect@4.0.0/src/internal/effect.ts) were fetched again; hashes `6781fd0ac6fad03057ebeaa838d0f9723913027a4f6845d57dc3c17da70d1953` and `68c43e18e167d17b39f224d3793f11c7732cd857b7908ecd3ff1d1edf0affac2` match installed sources. Names, bounded/make options and dual offer shape remain aligned with v4, with explicit IRType witnesses required for compiled authoring. The pinned upstream reentrant shutdown defect is already fixed upstream; shutdown/Done remain excluded here, so that defect does not affect this offer/take profile. Do not file another upstream issue.

## Decisions before implementation

- **QPUB-001 — Narrow authoring facade.** Export R.Queue and QueueIR as the same frozen public make/bounded/offer/take facade. Constructors require Bool/U64/Unit witnesses, literal capacity 1..3, suspend strategy and Never errors. Keep the richer internal QueueIR for reference/research; do not export End/shutdown/Done or an error-witness constructor argument. Reuse nodes and dual offer rather than duplicating semantics. Export QueueExecution and its option/observation types; it keeps the already checked owned default2048 context, captured immutable logs and intrinsic cancellation relay.
- **QPUB-002 — One checked compiler route.** Cache successful generated Queue profile checks per immutable Program, as the other coordinators do. Check before derive; plan and verify cannot trust a caller-supplied analysis or forged Plan. Preserve original profile/reference/growth/budget diagnostics. Retain audits for hidden Queue/Done expression signatures, marker channels and escapes. Generic lowerFunctions still refuses unchecked Queue; public Compile selects the checked Queue route. Report payload/error witnesses and AsyncResult/Tokio requirements, including owners with no payload operation.
- **QPUB-003 — Independent exports compose.** A module may contain independent admitted Queue/Deferred/Semaphore/Latch and ordinary functions. Extend Queue lowering to select their separate checked profiles and preserve runtime-service configuration. Coordinators cannot mix inside one function. Reuse one shared async context and one reachable runtime per family; no new scalar metadata or per-value wrapper. Actual emitted-byte and returned-future gates stay mandatory. None/Bounded frames and Full/None artifacts remain independent policies.
- **QPUB-004 — Keep host and topology limits explicit.** Require zero inputs, builtin scalar success/Never error, one root lexical owner, exactly one unconditional unnested All2 of Unit/Never children, with offer/take only in those children. Sleep/Ensuring, typed/Done errors, End/shutdown, resource Scope, nested/conditional/multiple groups, Race, parent operations and escaping/shared owners stay refused. NativeRpc explicitly rejects Queue before compiler selection because request ownership and Send behavior remain unverified. Reference execution uses QueueExecution for the supported default-context contract, not arbitrary ambient Effect composition.
- **QPUB-005 — Acceptance.** Public-only authoring/inference tests cover both constructors, dual offer, all scalar payloads/results, immutable success/framed/canceled observations and unopened preabort. Compile check/derive/plan/verify/emit tests cover target capability, owner representation reporting, policy independence, forged plans, structural/reference/budget/growth/marker refusals and RPC. Build and run actual public artifacts with None/Bounded and independent coordinator exports; retain existing debug/release Queue pressure/continuation/frame/cost tests. Public admission adds no native machinery, so existing measured costs remain regression gates. Keep native builds serial.

## Alternatives and remaining work

Exporting the full research object would imply End/shutdown/Done support without their retained-outcome/fail-fast/masking proof. Simply removing the blanket Queue compiler refusal would leave unchecked plans, hidden marker expressions, runtime selection and request hosting gaps. Reimplementing a separate public lowerer would duplicate semantic selection. The facade and existing checked route avoid those changes.

Broader APIs remain separate: End/shutdown/Done, fail-fast and retained errors, generated cleanup markers/masking, parent Queue operations, wider captures/owners/tasks/timers, RPC/Send, host-future abandonment, other capacity/overflow strategies and PubSub. No core PLAN.md edit is required; record this work in the module index, package docs and resume guide.

## Delivered implementation

The narrow facade, owned runner exports, checked compiler routing and explicit RPC refusal are implemented. Independent coordinator exports share the existing AsyncContext while retaining per-function profile checks; injected Clock/Random service selections survive Queue routing. Idle owners report their payload/error representations and AsyncResult even without operations. Hidden marker signatures and forged analyses/plans cannot bypass admission.

`queue-public.test.ts` covers public inference and negative type contracts, owned success/cancellation/preabort, Full/None artifacts and None/Bounded frames, profile/marker/budget/growth/target/host refusals, and actual public Cargo artifacts. Existing private generated debug/release conformance and cost fixtures remain required regressions. No new native runtime storage, dependencies or scalar metadata are introduced by public routing. Validation results are recorded in PROGRESS.md.

- **QENDPUB-005 — Acceptance and exclusions.** Public-only inference/type tests, constructor overloads, authored/checked/derived/planned/verified/emitted artifacts, representation reports and forged analyses/plans. ### QALLPUB-006 — Recorded outer failure frames

Final review identified a framing boundary: an outer canceled framed interpreter can bypass its result envelope, leaving a private FramedDomain carrier. Merely preserving that outer Cause would both hide recorded frames and misstate the public Done error type. Add an internal framed-Cause projection that unwraps only trusted interpreter carriers, preserves public error payloads and Cause annotations, and exposes their recorded trail without appending unobserved boundaries. All-specific packaging validates projected errors as CompileError or canonical unit Done; invalid payloads are an explicit observation diagnostic rather than leaked private values. CompileError-containing failures remain outer. For represented runtime causes, attach the actual recorded source trail, or the existing boundary snapshot when no source trail exists. Preserve every reason; only the local interrupt-only path uses its existing normalization. Preabort with no recorded boundary remains unopened/unframed.

Meaningful pure adapter tests inject mixed public Done/Interrupt, trusted framed Done and CompileError. They prove packaging, reason/payload/annotation retention and no invented frames, not naturally reachable owned JS scheduling. Native boundary-injection and ordinary natural-signal evidence remain separate. This is context-owned observation metadata; native emit/runtime/payload layouts remain unchanged.

- **QCLEANPUB-001 — Existing exact receipt.** Public compiler selects analyzeGeneratedQueueCleanupProfile/lowerQueueCleanupFunctions. Ordinary/local/All functions retain their receipts. ### QCLEANPUB-006 — Cancellation with another child's Done

The public ownership test must also cover queue-free child0 cleanup while plain child1 End→Take fails. Parent cancellation during the entered child0 timer must retain child1 Done, await cleanup and bypass recovery. Native evidence needs the same case in the public matrix, including its source/parent trail without another child's Ensuring. This distinguishes semantic outcome retention from cleanup ownership and prevents either a blanket inferred boundary or loss of a non-finalizing child's Done.
