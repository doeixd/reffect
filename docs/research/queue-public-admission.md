# Bounded public Queue admission

Prepared 2026-10-07 against AGENTS, PLAN/PROGRESS, QGEN/QBUD/QEXEC/QFRAME, shared owned cancellation and the Latch/Semaphore/Deferred public compiler routes. Public exposure reuses the verified private offer/take profile; it does not broaden Queue scheduling or ownership.

## Primary evidence

Published [Effect 4.0.0 Queue.ts](https://unpkg.com/effect@4.0.0/src/Queue.ts) and [internal/effect.ts](https://unpkg.com/effect@4.0.0/src/internal/effect.ts) were fetched again; hashes `6781fd0ac6fad03057ebeaa838d0f9723913027a4f6845d57dc3c17da70d1953` and `68c43e18e167d17b39f224d3793f11c7732cd857b7908ecd3ff1d1edf0affac2` match installed sources. Names, bounded/make options and dual offer shape remain aligned with v4, with explicit IRType witnesses required for compiled authoring. The pinned upstream reentrant shutdown defect is already fixed upstream; shutdown/Done remain excluded here, so that defect does not affect this offer/take profile. Do not file another upstream issue.

## Decisions before implementation

- **QPUB-001 — Narrow authoring facade.** Export R.Queue and QueueIR as the same frozen public make/bounded/offer/take facade. Constructors require Bool/U64/Unit witnesses, literal capacity 1..3, suspend strategy and Never errors. Keep the richer internal QueueIR for reference/research; do not export End/shutdown/Done or an error-witness constructor argument. Reuse nodes and dual offer rather than duplicating semantics. Export QueueExecution and its option/observation types; it keeps the already checked owned default2048 context, captured immutable logs and intrinsic cancellation relay.
- **QPUB-002 — One checked compiler route.** Cache successful generated Queue profile checks per immutable Program, as the other coordinators do. Check before derive; plan and verify cannot trust a caller-supplied analysis or forged Plan. Preserve original profile/reference/growth/budget diagnostics. Retain audits for hidden Queue/Done expression signatures, marker channels and escapes. Generic lowerFunctions still refuses unchecked Queue; public Compile selects the checked Queue route. Report payload/error witnesses and AsyncResult/Tokio requirements, including owners with no payload operation.
- **QPUB-003 — Independent exports compose.** A module may contain independent admitted Queue/Deferred/Semaphore/Latch and ordinary functions. Extend Queue lowering to select their separate checked profiles and preserve runtime-service configuration. Coordinators cannot mix inside one function. Reuse one shared async context and one reachable runtime per family; no new scalar metadata or per-value wrapper. Actual emitted-byte and returned-future gates stay mandatory. None/Bounded frames and Full/None artifacts remain independent policies.
- **QPUB-004 — Keep host and topology limits explicit.** Require zero inputs, builtin scalar success/Never error, one root lexical owner, exactly one unconditional unnested All2 of Unit/Never children, with offer/take only in those children. Sleep/Ensuring, typed/Done errors, End/shutdown, resource Scope, nested/conditional/multiple groups, Race, parent operations and escaping/shared owners stay refused. NativeRpc explicitly rejects Queue before compiler selection because request ownership and Send behavior remain unverified. Reference execution uses QueueExecution for the supported default-context contract, not arbitrary ambient Effect composition.
- **QPUB-005 — Acceptance.** Public-only authoring/inference tests cover both constructors, dual offer, all scalar payloads/results, immutable success/framed/canceled observations and unopened preabort. Compile check/derive/plan/verify/emit tests cover target capability, owner representation reporting, policy independence, forged plans, structural/reference/budget/growth/marker refusals and RPC. Build and run actual public artifacts with None/Bounded and independent coordinator exports; retain existing debug/release Queue pressure/continuation/frame/cost tests. Public admission adds no native machinery, so existing measured costs remain regression gates. Keep native builds serial.

## Alternatives and remaining work

Exporting the full research object would imply End/shutdown/Done support without their retained-outcome/fail-fast/masking proof. Simply removing the blanket Queue compiler refusal would leave unchecked plans, hidden marker expressions, runtime selection and request hosting gaps. Reimplementing a separate public lowerer would duplicate semantic selection. The facade and existing checked route avoid those changes.

Broader APIs remain separate: End/shutdown/Done, fail-fast and retained errors, generated cleanup markers/masking, parent Queue operations, wider captures/owners/tasks/timers, RPC/Send, host-future abandonment, other capacity/overflow strategies and PubSub. No core PLAN.md edit is required; record this work in the module index, package docs and resume guide.

## Delivered implementation

The narrow facade, owned runner exports, checked compiler routing and explicit RPC refusal are implemented. Independent coordinator exports share the existing AsyncContext while retaining per-function profile checks; injected Clock/Random service selections survive Queue routing. Idle owners report their payload/error representations and AsyncResult even without operations. Hidden marker signatures and forged analyses/plans cannot bypass admission.

`queue-public.test.ts` covers public inference and negative type contracts, owned success/cancellation/preabort, Full/None artifacts and None/Bounded frames, profile/marker/budget/growth/target/host refusals, and actual public Cargo artifacts. Existing private generated debug/release conformance and cost fixtures remain required regressions. No new native runtime storage, dependencies or scalar metadata are introduced by public routing. Validation results are recorded in PROGRESS.md.

## Public End and unit Done — preparation 2026-10-08

Reviewed QDONE/QGALL/QGCLEAN/QGSHUT, current compiler/owned runner, marker and representation guards, PLAN/PROGRESS and public/private regressions. Fresh [Effect 4.0.0 Queue.ts](https://unpkg.com/effect@4.0.0/src/Queue.ts) SHA256 `6781fd0ac6fad03057ebeaa838d0f9723913027a4f6845d57dc3c17da70d1953` matches installed source: constructors default E=never; End returns boolean and records unit Cause.Done. Existing checked local-Done lowering has native category, frames, allocation/root and mixed-module evidence. Broader retained All and cleanup/Shutdown proofs are separate profiles with stronger observation contracts.

- **QENDPUB-001 — Explicit witness, aligned functions.** Export canonical `QueueDoneType` alongside other root IRType witnesses. Public Queue.make/bounded add a mandatory third error-witness overload, constrained to unit Cause.Done (Never also remains valid); existing two-argument constructors still return Never queues. Do not allow an explicit error type parameter with an omitted witness. Add existing End implementation to the facade; it requires the canonical unit Done owner and returns boolean. No new IR node or Cause value constructor, no generic Done payload support. Keep Shutdown absent.
- **QENDPUB-002 — Select the proved local profile.** Compiler and QueueExecution select analyzeGeneratedQueueDoneProfile; compiler emits through lowerQueueDoneFunctions. This includes unchanged ordinary functions and completion-capable idle owners. Each take Done must be caught inside its child, with scalar/Never handlers and final function channels. Root All recovery, timers/finalizers, source yields, broader groups/owners, scalar-error mixing and RPC stay refused. Existing strict default2048, growth, provenance and owned cancellation guarantees remain.
- **QENDPUB-003 — Narrow marker/representation admission.** Permit exact Done computation error channels only for a function with a checked End receipt; retain all payload/signature/composite/hidden pure-operation marker guards. Verify represents QueueDoneType only when checked completion receipts exist, after program re-derivation and marker audit. Keep kernel pure marker guards and ordinary analyzers/lowerers unchanged. Do not add Done to the global scalar classifier. Retain the explicit Done witness in analysis.types/support explanation.
- **QENDPUB-004 — Owned observations and cost.** Because admitted final channels are Never and children handle domain failures locally, QueueExecution's existing Exit/FramedExit typing remains valid. Check End drains, false repeated End, buffered successful takes, child-local recovery and actual cancellation/preabort, including immutable copied exit logs. None/Bounded and Full/None remain independent. Existing frame disposal and zero quiet disabled allocation/layout receipts apply; no new native fields/crates/metadata. Broader retained Cause reporting requires a separate public observation design.
- **QENDPUB-005 — Acceptance and exclusions.** Public-only inference/type tests, constructor overloads, authored/checked/derived/planned/verified/emitted artifacts, representation reports and forged analyses/plans. Hidden Done values/signatures/binders, noncanonical witnesses, uncaught/escaping Done, root All catch, cleanup, Shutdown, service/RPC hosting and budget/growth/context violations must fail. Build actual public artifacts under both frame/artifact policies and debug/release; compare owned reference traces and preserve older ordinary module bytes. Update existing private test expectations only where public admission intentionally changes.

Alternatives: expose all private profiles at once (retained Cause/cleanup observation and stronger gates would become public commitments), hide Done as Unit/Never (unsound), place a new non-v4 terminal helper on Queue, or broaden all type representation checks. Root QueueDoneType is an explicit representation witness consistent with existing exported BoolType/UnitType, not a new Queue/Cause runtime operation. PLAN.md belongs to the core instance.

## Public End integration

The public facade and root witness reuse the canonical IR and existing local-Done runtime. Public compiler/owned runner select only the checked local completion profile; private retained All, cleanup and Shutdown selectors remain separate. Constructor implementation return unions preserve invariant channel types without casts while public overloads require the witness for an explicit completion channel. Independent review found no production admission blocker. Validation must inspect the inner Exit of framed interruption observations; the outer Exit succeeds when observation itself succeeds. Public artifacts are compared byte-for-byte with the previously audited local emitter, alongside native differential, disposal and cost assertions. Final validation results are recorded in PROGRESS.md.

The public completion matrix passes all eight artifact/frame/debug/release configurations and two negative mutations through Compile.run. Public emission equals the previous private local emitter byte-for-byte; official reference and owned runner traces agree, including cancellation inside the framed observation. Native quiet construction allocates zero; quiet execution allocates zero under None or one released trail per handled Done under Bounded. Independent source admission review found no blocker. The old public artifact fixture's budget helper now receives zero process failures plus an explicit 240-second extension; passing milliseconds as a failure count previously produced the wrong Linux budget and Windows timer overflow.

### Reproduce public validation

From the repository root, use the installed vp/tsc binaries and Cargo environment. Keep both native suites serial and isolated from the workspace checker.

```sh
export PATH="$PWD/node_modules/.bin:$PATH"
. "$HOME/.cargo/env"
vp check
tsc --noEmit -p packages/reffect/tsconfig.json
vp run -r build
vp test packages/reffect/tests/queue-public-done.test.ts --maxWorkers=1 --testTimeout=30000
CARGO_PROFILE_DEV_DEBUG=0 CARGO_INCREMENTAL=0 CARGO_BUILD_JOBS=1 vp test packages/reffect/tests/queue-generated-done.test.ts --maxWorkers=1 --testTimeout=30000
CARGO_PROFILE_DEV_DEBUG=0 CARGO_INCREMENTAL=0 CARGO_BUILD_JOBS=1 vp test packages/reffect/tests/queue-public.test.ts --maxWorkers=1 --testTimeout=30000
```

The native tests set their own longer per-test budgets; the 30-second CLI budget applies to the inexpensive checks. The delivered full workspace run used `vp check --fix`; final build verification after the timeout-only review was entirely cached. The six legacy non-Cargo suites are queue-ir, queue-execution, queue-budget, queue-generated-profile, queue-lowering and queue-public-done (40 tests); their run used `--maxWorkers=1 --testTimeout=30000`.
