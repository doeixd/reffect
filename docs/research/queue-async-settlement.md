# Private Queue asynchronous settlement

Preparation checked 2026-10-07; this extends [QINT](queue-interruption-settlement.md), [QOWN](queue-driver-ownership.md) and [QCB](queue-continuation-bridge.md). It does not admit Queue into generated/public execution.

## Evidence and alternatives

Pinned [Effect 4.0.0 internal source](https://unpkg.com/effect@4.0.0/src/internal/effect.ts) matches installed bytes (SHA256 `68c43e18e167d17b39f224d3793f11c7732cd857b7908ecd3ff1d1edf0affac2`). `interruptAll` visits children in order through their first suspension, then awaits all; masked OnExit cleanup survives late cancellation. Two official probes establish that a sleeping first finalizer lets the second child's cleanup finish before the first wakes, and cancellation during normally entered masked cleanup yields interruption only after cleanup finishes.

[Tokio 1.53.1 Sleep](https://docs.rs/tokio/1.53.1/tokio/time/fn.sleep.html) must remain pinned and be constructed inside a timer-enabled runtime. [watch Receiver](https://docs.rs/tokio/1.53.1/tokio/sync/watch/struct.Receiver.html) supplies cancellation-safe wake registration; false updates are not cancellation, disconnection is cancellation under existing AsyncContext policy. Reuse `asyncRuntime(false, false)` rather than adding per-child cancellation channels or a second host runtime.

Waiting for each child to finish before interrupting its sibling fails the sleeping-finalizer trace. Dropping a future skips authored cleanup. Spawning children or boxing heterogeneous futures adds ownership/allocation and scheduling changes unnecessary for this borrowed experiment. Generic foreign Pending cannot establish masking or semantic boundaries.

## Decisions

- **QASYNC-001 — Explicit managed suspension.** Extend the bridge with an inline per-child cleanup-wait marker and CleanupWaiting boundary. Only the adapter's masked AsyncContext Sleep may set it. Posted Queue requests take priority; arbitrary foreign futures remain refused. Pass an immutable actual host Waker through every initiating and callback poll, constructing a fresh short Context per poll.
- **QASYNC-002 — Initiate, then settle.** Cancellation visits child0 then child1 through completion or the first managed suspension, then resumes managed cleanup until both complete. A child already in masked cleanup receives sticky interruption without replacing its pinned Sleep or inventing a Queue ticket. Synchronous APIs retain their complete-cleanup assertion. Drop remains registration retirement, never finalizer execution.
- **QASYNC-003 — Borrowed host boundary.** A private adapter monitors the existing watch receiver, including true/disconnected preflight and a final cancellation check after cleanup. False updates register again without a busy loop. Already cancelled owned execution polls no child. This is the existing owned-boundary policy, not a claim about bare Effect RunOptions preabort behavior. Cancellation is checked between startup child polls and before scheduled Queue dispatch; fixture triggers deliberately establish that boundary.
- **QASYNC-004 — Mask and representation.** Cleanup saves/restores AsyncContext interruptibility with a drop guard and keeps Sleep pinned. No payload metadata, spawn, box, Arc owner or child channels. RefCell/Cell make this adapter non-Send: use current-thread Tokio only. Measure bank/context/child/root layouts separately; do not infer allocation freedom for a host/timer from the std-only driver.
- **QASYNC-005 — Admission remains closed.** This is a two-child scalar/Never borrowed prototype, with one positive timer cleanup and synchronous peer cleanup/shutdown. Competing/tied timers, arbitrary async cleanup, fallible cleanup/Cause/Exit, frames, checked operation/default-yield receipts, generated IR lowering and RPC/multithread ownership remain gates. Cancellation emitted inside a scheduled callback is only observed after dispatch returns; intra-dispatch parent-cancellation ordering is unproved. Dropping/selecting away the hosted future abandons execution: it does not await authored cleanup; the borrowed child must itself be destroyed to restore an active mask, and driver Drop only retires registrations. The pinned reentrant-shutdown defect remains independently unresolved for public admission.

## Acceptance

Compare exact official traces in debug/release for interrupted sleeping cleanup, late cancellation of normal masked cleanup, and synchronous shutdown settlement. Probe preabort/disconnection, false updates and a masked parent locally; label local safety evidence separately. Bound tests with host timeouts. Negative mutations must catch skipped settlement and missing real Waker propagation. Re-run std Queue regressions, strict TypeScript, full workspace check/build; native builds serial. Record measured costs and remaining gates before delivery.

## Delivered evidence

Four exact official traces pass in debug/release: interrupted timer cleanup, synchronous shutdown settlement, late cancellation during normal masked cleanup, and a producer finalizer starting Sleep inside a consumer capacity-release callback. The callback trace is `producer:A → producer:B → cleanup:start → consumer:A → cleanup:awake → shutdown:true → cleanup:end → parent:settled`. No-op Waker propagation fails the bounded watchdog; early hosted return fails actual child-completion assertions. A biased watchdog is intentional: Tokio timeout polls its inner future before the deadline, which can conceal a missing timer wake by supplying a late wake itself.

Local probes cover disconnected cancellation while blocked, true/disconnected preflight, false watch updates, masked root context and saved-mask restoration when a child cleanup future is destroyed. These prove fixture safety, not arbitrary external scheduling or full Effect Exit parity. Independent review found no blocker within QASYNC and identified the documented intra-dispatch cancellation and hosted-future abandonment limits.

On Linux x86_64, bridge/AsyncContext/task/borrowed driver/host future sizes are144/24/16/72/232 bytes; actual sleeping-cleanup/producer child futures376/120 bytes. The two new marker cells fit existing bridge padding. Ordinary scalar payloads remain unchanged. Construction/execution of1000 quiet hosted groups allocates0 times, with and without one masked1ms Sleep, after warming the current-thread timer runtime. The original watch channel and runtime are created outside the measured region; receiver cloning, bridge/driver/child/root construction and timer execution are included. This does not claim zero host setup allocation, multithread costs, or checked generated root costs.
