# Bounded Effect v4 Option module

Research baseline: installed `effect` 4.0.0-rc.118, checked against the [pinned upstream Option source](https://unpkg.com/effect@4.0.0-rc.118/src/Option.ts) on 2026-10-02. `none`, `some`, `match`, `map`, `flatMap`, `getOrElse`, `orElse`, `filter`, `exists`, `as`, `asVoid`, `flatten`, `tap`, `zipLeft`, `zipRight`, `fromUndefinedOr` and `getOrUndefined` define the semantic oracle. Upstream `match` branches on `isNone`; transformations preserve absence and callbacks run only for the selected branch at execution time. Reffect callbacks construct both symbolic branches once at authoring time.

## Decisions before implementation

- **OPTION-001 — Reuse tagged-union IR.** Represent `None` as an empty case and `Some` as a case with required `value: T`. Existing matching, ownership, reference, native emission and codecs supply the complete path. Alternative: add an Option layout/node family using Rust `Option<T>` directly. Revisit when generated size/layout measurements justify a dedicated representation. This first implementation adds no runtime registry, Cargo dependency or per-value metadata; a scalar payload is stored inline in the generated enum. Existing composite cloning rules still apply.
- **OPTION-002 — Structural values, explicit missing witness.** `OptionValue<T>` is the readonly tagged data projection of Effect Option, not a branded/prototyped Effect instance. `some(expr)` infers T; `none(T)` needs a witness because native representation cannot be inferred from absence. `Option(T)` is the callable witness factory. Alternatives: hydrate official instances in the reference, or infer polymorphic None through a new bottom-value IR. Both would widen shared machinery. Revisit for a stock Effect Option codec or polymorphic authoring workload. `isOption` and official instance `.pipe`/iteration are not claimed; compiled expressions themselves are pipeable.
- **OPTION-003 — Pure bounded branch results.** `match`, `getOrElse` and `orElse` require compatible result witnesses; callbacks return pure Expr. Upstream heterogeneous JS unions and effectful callback values need explicit representable witnesses, and are not silently erased. `flatMap` verifies an Option result. Alternative: introduce untagged union representation or overloaded effectful matching; defer until a concrete workload. Revisit after Result/effect bridge semantics land.
- **OPTION-004 — Preserve Some(undefined) and nesting.** Unit and nested Option payloads are admitted. They remain distinct from None; this deliberately uses tagged unions rather than conflating Option with `UndefinedOr`. Conversions through `UndefinedOr` are limited to item witnesses that do not themselves admit undefined, as required by the existing `UndefinedOr` contract. Alternative: collapse absence into undefined; rejected because it loses observable states.
- **OPTION-005 — Reuse existing witness interning.** The Option factory uses existing structural TaggedUnion interning; repeated identical item witnesses share the same witness. Module operations verify canonical None/Some structure and item identity before building branches. No additional module-level strong or weak registry is introduced. The existing composite witness interner retains encountered witnesses in the TypeScript authoring process; it is not a native per-value cost. Revisit global interner ownership separately with compiler heap measurements.

## Deferred surface

Nullable conversions need a null witness; throwable getters need admitted defect semantics. Iterable/product/all/Do/generator helpers and equality/order helpers remain workload-driven additions. These omissions are explicit, not a claim that all upstream Option APIs are supported. Schema is a tagged data schema, not Effect's branded `Schema.Option` constructor.

## Evidence

- Focused command: `env CARGO_PROFILE_DEV_DEBUG=0 CARGO_INCREMENTAL=0 vp test packages/reffect/tests/option.test.ts --maxWorkers=1` (Rust environment loaded). **3/3 pass**, 7.90 seconds total, 6.06 seconds tests; fresh generated crate built in debug and release. The native artifact has no additional Cargo crates.
- Differential cases cover absence/presence, mapping, chained failure-to-None, predicates, fallback, zip/tap, nested Options, Some(Unit), UndefinedOr round trips, string ownership/reuse and skipping overflowing arithmetic in an unselected branch. Type fixtures refuse mismatched fallbacks and non-Option flatMap results without author casts.
- `vp lint packages/reffect/src/option.ts packages/reffect/tests/option.test.ts` passes. Package strict TypeScript initially reports no Option diagnostics but is blocked by concurrent integration errors in `authoring.ts` (duplicate `not`) and `result.test.ts` (unavailable artifact `plan` property); parent owns integrated resolution and final checks.
- Native layout/allocation size is not measured by this module; inline enum storage follows generated source, not a new benchmark claim. `map` and `flatMap` create a symbolic callback once and reuse existing capture-free substitution; its temporary graph walk/memo Map is a TypeScript authoring cost. Deep composition currently expands existing MatchTags IR and follows the compiler's conservative composite cloning, so code-size/clone elimination remain measurement-driven follow-ups.
