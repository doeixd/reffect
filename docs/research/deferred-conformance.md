# Lexical Deferred conformance preparation

Recorded 2026-10-03 against installed Effect 4.0.0 and [published stable Deferred source](https://unpkg.com/effect@4.0.0/src/Deferred.ts), before implementing the new conformance fixtures. This follows [lexical coordination](lexical-coordination.md), especially LCOORD-008, and [the native adapter](deferred-native.md). The existing task kernel, fallible Cause, opaque-handle and cancellation admission gates still apply.

## Independent evidence and decisions

- **DEFERCONF-001 — Explicit isolation barrier.** Use three independent official Deferred owners: retained main payload, Unit cancel signal and Unit canceled-waiter-finalized signal. The outer All contains one inner Never Race, another main waiter and a producer. The producer releases the cancel signal, waits for the canceled waiter's ensuring signal, then completes main. This proves independent cancellation before completion without a wall timer, rather than letting a fast completion mask an unregister bug.
- **DEFERCONF-002 — Observable outcome and causal order.** Compare independently authored official/plain/framed/native programs. Assert finalized-canceled-waiter before main completion, main completion before surviving payload observation, registered surviving continuation before the producer observes first(true), inner Race only finishes after canceled cleanup, and late observation after group completion. Preserve registration-order broadcast callback prefixes and reentrant completion order; do not canonicalize across these boundaries. Stable completion resumes waiter callbacks synchronously, so a native Waker scheduling approximation is insufficient. The bounded adapter must satisfy these traces or refuse the unsupported program. The precise completion acknowledgment protocol is under review; acknowledging only an await poll/drop does not prove callback-prefix ordering.
- **DEFERCONF-003 — Retained immutable outcome.** Assert first and repeated completion return true/false, every surviving broadcast waiter and late waiter reads the first payload/error, and isDone transitions false to true. Typed failure is independently caught by each waiter so fail-fast All cancellation cannot hide a missing broadcast.
- **DEFERCONF-004 — Lifetime and policies.** Compare both native profiles and frame policies. Parent cancellation must finalize waiters before lexical owner close. Opaque handles cannot escape through returned values or aggregate channels. State-unit race/registration/Waker/drop checks and layout/allocation measurements supplement authored semantics; they do not replace the independent isolation witness.

The official LCOORD-008 probe produced finalized, inner-race-done, complete-main, survivor(7), first(true), second(false), late(7). First completion retains 7 despite the second attempted value 9. Another timer-driven probe placed survivor(7) before first(true), confirming that a registered surviving callback runs before the producer observes its completion Boolean. A timer-driven probe is supplementary evidence, not the controlled registration proof.

## Acceptance

Broadcast to two waiters plus retained late success; retained typed failure to two independently recovered waiters plus late recovery; first-completion Boolean for success/failure and cross-channel losing completion; completion before any await; independent canceled waiter with surviving waiter; parent cancellation with awaited finalization; compile-time lifetime/refusal checks; and no change to ordinary task/context costs when Deferred is unreachable. Support remains the recorded scalar lexical subset, excluding done/failCause/complete/completeWith and general Fiber handles.

**DEFERCONF-005 — Reentrant callback ordering remains observable.** Register w1 and w2 on main, and another waiter on secondary. When w1 receives main it completes secondary. Official Effect resumes the secondary callback before main w2. A native adapter that acknowledges w1 merely because its await returned, then resumes w2 while w1 is suspended in secondary completion, violates this order. Add an independently authored fixture once the bounded protocol/admission policy is chosen; do not silently sort this trace.

## Current preparation status

The independent no-timer oracle was rerun during synchronization and reproduced the seven-event isolation trace above. A proposed conformance draft remains outside the repository at `/tmp/reffect-deferred-probes/deferred-conformance.test.ts`; it is deliberately not a shipped test or acceptance claim. It covers isolation, two registered broadcast waiters, independently caught retained failure, completion before await, and parent interruption with waiter finalizers before owner finalization. The first registered broadcast callback must precede the second, and both callback prefixes must precede the successful completion Boolean. Debug/release and None/Bounded native comparisons remain pending.

Feature test publication waits for a verified semantic-turn coordinator or an explicit compiler refusal for traces that its narrower adapter cannot reproduce. A per-await acknowledgment alone is insufficient: the callback can synchronously enter another completion, await, nested task group or masked finalizer. Reentrant completion must preserve the resulting callback order, and an acknowledgment must neither resume the next waiter prematurely nor deadlock while a callback parks. Independent waiter cancellation and retained outcomes remain mandatory acceptance conditions after this gate.
