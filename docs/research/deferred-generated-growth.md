## Decisions before implementation

**DGROW-001 — Add a separate private structural receipt.** Sum all expanded computation and expression occurrences, including both Match branches, task children and finalizers. Memoize subtree summaries by immutable node identity, then recharge the summary at every incoming edge. Count wrappers sharing a node consistently; memoization avoids exponential analysis but does not subtract repeated occurrence costs. Saturate counters just above each limit and refuse cycles/unaccounted nodes. Include maximum computation-helper nesting and expression nesting. This deliberately overcounts cheap shared expressions rather than needing a second scope-sensitive lowerer. The receipt is a conservative structural bound, not an exact helper count, native byte size or rustc query count.

Self-review identifies an ordering hazard: topology and the owned runner's trusted-reference checks recurse before this new receipt. Reuse the existing iterative `nestingDepth`/512 preflight before those recursive passes, including fn-only standalone execution. This preserves the project-wide nesting invariant and returns typed `NESTING_LIMIT` rather than a JavaScript stack overflow on extremely deep input. The private 50-level weighted limit remains a separate stricter gate.

**DGROW-002 — Provisional explicit limits.** Per private function: at most **50 computation levels**, **512 computation occurrences**, **64 expression levels**, **4096 expression occurrences**, and **65536 UTF-8 bytes** of authored string literals/log text. Across private functions in one module: at most **4096 computation occurrences**, **32768 expression occurrences**, and **262144 authored text bytes**. These are internal profile limits, not user assertions or override options. The depth boundary preserves the measured 48-Map chain and existing 40-Map truncation witness; the count boundary refuses the concrete shared-branch expansion independently of execution costs. Diagnose a violated dimension and its path before recursive type/binder checking, scope adaptation, provenance or helper generation. Existing topology, ownership, scheduler and observer budgets still apply independently.

Reserve additional depth for group machinery: count a TaskGroup as **four levels**, allowing three extra units for its whole-task wrapper/driver stack. Other admitted computations count one. This is a conservative structural allowance for generated nesting, not an equality with rustc queries; the boundary group witness must compile with the actual finite crate setting. Count every computation occurrence once for the separate expansion limit.

**DGROW-003 — Align scalar expression support.** Analyze the already audited standalone scalar expression shapes: Parameter, Literal, Apply and Match, with builtin Bool/U64/Unit/String/Number witnesses. Compound value/layout expressions remain outside this private growth receipt and receive an explicit unaccounted diagnostic; ordinary compiler support is unchanged. This avoids treating a one-node compound witness with arbitrarily many fields as a small native representation. Scalar computation/Deferred payload channels retain the existing Bool/U64/Unit/Never restriction. Count string text from immutable builder IR without invoking user serialization. Operation implementations remain compiler registry inputs; their arbitrary template bytes require a separate emitted-source cap.

**DGROW-004 — Gate actual emitted Rust too.** For a module containing private Deferred functions, require at most **2097152 UTF-8 bytes** across emitted Rust files. Count actual output, including selected runtime modules and entry code, independently of source-artifact policy or failure-frame policy. This catches huge registry templates, identifiers and escaping expansion that an IR-node receipt cannot predict. The emission check is an additional refusal after writing; it is not a bound on peak compiler heap or arbitrary build inputs. Modules without private Deferred keep their existing emission behavior. Mixed modules share this explicit private crate limit.

**DGROW-005 — Keep byte evidence honest.** Structural limits bound a finite admitted graph family and reject known native/code-growth failures; they do not prove a portable maximum future size. Compile boundary workloads in debug/release and None/Bounded: maximum depth, a near-bound shared branching graph, and a group with the supported inner Race and a deep child. Compare results/interruption and record measured future sizes. Reuse NSTORE-004's pointer-scaled `2560 * sizeof(usize)` future regression budget for these boundary workloads (20480 bytes on x86-64), alongside existing relative capture-growth budgets. This extends the measured fixture family, not a universal ABI guarantee. General compiler-version/target drift, actual per-program layout admission, peak heap, wide scalar captures and public Deferred remain open. Do not add Box, metadata fields, task spawning or scheduler changes to make the fixtures pass.

Alternatives: increasing recursion limits merely moves the known failure and allows growth to continue; stable `type_length_limit` is ineffective; max-branch execution counts miss dormant code; scope-exact helper simulation duplicates lowerer semantics; inferred future-byte formulas would claim an unspecified ABI; invoking Cargo for every standalone reference run adds a host dependency. The chosen structural receipt runs before existing expensive checking, with actual emitted output checked separately.

## Acceptance

- Existing native cancellation/order/cleanup, shared paths, truncated trails, capture growth and zero-allocation witnesses remain admitted and passing.
- An execution-admitted deep chain and compact shared branching graph refuse in private reference/standalone/native entry before source work. Expression depth, repeated expression DAG costs, UTF-8 text, exact boundaries, aggregate module receipts and emitted-byte overflow have meaningful tests.
- Preserve the near-bound scheduler witness using two shallower sequential Map chains; the whole invocation still approaches 2048, while each native helper chain respects the independent depth limit.
- Actual generated boundary workloads compile and run under all four native frame/build policies. Record results and layout observations separately from structural summaries.
- Ordinary public Deferred refusal and ordinary emitted artifacts remain unchanged. Decisions and remaining gates stay linked from progress and open work.

## Delivered evidence

The initial sequential native sweep passes **21/21 across four suites (274.46s)**: new boundary admission/layouts, exact interrupted paths, nested cancellation/order/storage and quiet helper capture costs. It exercises 104 native workload/frame/build cases; the existing quiet suite retains zero allocations across 2800 metered invocations. Refined the branching workload to actual asynchronous Deferred completion (444 expanded computations), then tightened all new boundary futures to NSTORE-004's existing 2560-pointer budget. The final boundary suite passes **10/10 (71.26s)**, including the 4096-Map typed preflight refusal and twelve actual native boundary cases.

Debug/release layouts agree on Rust 1.98.1/x86-64. These are observations, not portable layout assertions. Every new future remains below 20480 bytes; the deeper field-free chain previously failed the actual 256 query allowance. The branch family has many helpers but Rust overlays mutually exclusive states; occurrence counts intentionally bound code expansion rather than predict byte layout.

Focused JavaScript checking passes 29/29 across four suites (7.00s; two native tests excluded), followed by **38/38 across six integration suites (14.38s; one native test excluded)**. This preserves owned contexts, near-limit automatic-yield receipts, private/public refusal, source pipelines, shared-path budgets and interruption behavior. Exact expression/text/function/module/source-size boundaries pass, including same-function export aggregation and ordinary output preserved without private Deferred. Full check passes 467 formatted files and 284 TypeScript files; strict package TypeScript and rebuilt workspace pass. Final post-commit checks follow after recording refinements.

Independent review finds no concrete metric/lifetime defect: every incoming edge recharges its summary, cached suffix heights respect the current prefix, group depth weighting is applied consistently, module aggregation is incremental, UTF-8 counts saturate without an encoded copy, and source limits are independent of metadata/frame policy. Self-review adds the iterative nesting preflight before recursive topology/trusted-reference checks, labels emitted-size errors with stage `emit`, and allocates checker key/type tables once per analysis. Native emission bodies/runtime, scalar/context representations, scheduling and source-map coordinates stay unchanged.

Remaining gates: actual per-program native layout/target/compiler-version admission, maximum retained/peak compiler heap, richer outcomes and wider scalar-capture families, and integrating the owned standalone context with public admission. Structural bounds are a bounded private profile, not a promise that every admitted future on every Rust target fits a portable byte budget.
