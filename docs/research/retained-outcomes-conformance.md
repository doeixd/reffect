# Retained outcomes conformance

Preparation checked 2026-10-04 against installed Effect 4.0.0 and the [published implementation](https://unpkg.com/effect@4.0.0/src/internal/effect.ts), including `ensuring`, `catchCause`, `raceAll` and the fiber continuation evaluator. This extends [fallible conformance](fallible-conformance.md) and the retained-child witness in [Deferred ownership](deferred-ownership.md). Public Deferred admission remains a separate gate.

## Decisions before implementation

| ID          | Decision                                                                                                                                                                                                               | Reason / revisit trigger                                                                                                                                                                        |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| RETCONF-001 | Author official Effect programs independently of R programs, and compare ordered reason kinds/payloads plus cleanup events.                                                                                            | A declared `Never` error channel does not describe every interrupted runtime outcome.                                                                                                           |
| RETCONF-002 | Use TestClock for Effect and a paused Tokio clock for native programs. Require the cleanup-entry log before interruption; native polling occurs before advancing the cleanup timer.                                    | Cancellation must arrive after the failure is selected and while masked cleanup is suspended. Wall-clock sleeps do not prove this ordering.                                                     |
| RETCONF-003 | Exercise root recovery, All child recovery and Race child recovery independently, including unchanged error channels, Bool and Unit.                                                                                   | Root retains the original failure; All combines parent interruption with the retained child failure; Race projects parent interruption alone. These policies cannot share a blanket projection. |
| RETCONF-004 | Exercise Race after a success is selected while a recovered loser is still finalizing. Assert cleanup drains and no typed catch callback runs after cancellation.                                                      | A selected success does not permit abandoning loser resources or executing cancellation-suppressed recovery.                                                                                    |
| RETCONF-005 | Run native debug/release under None/Bounded failure frames; keep payload extraction separate from frames. Preserve explicit refusal for retained composite outcomes and admission for synchronous/non-failing sources. | Carrier selection must follow reachable outcomes without taxing unrelated programs or widening the scalar profile.                                                                              |

The native fixture's first Pending is sufficient only for these straight-line bodies: each failing branch logs cleanup entry immediately before its sole timer, and other branches either park on a long timer or immediately log success. The event assertion independently confirms this premise after execution. No arbitrary scheduler or general first-Pending proof is claimed.

The observation profile excludes interruptor identity and general Die/annotation semantics. Unexpected defects fail the fixture rather than being erased. Native observations read the generated runtime carrier directly without widening the public Fail-only Cause witness.

## Acceptance

Root Fail(7) + awaited ensuring + typed catch (both Never and same-error): cancellation during cleanup preserves Fail(7), skips catch, and completes cleanup. All with that child yields Interrupt then Fail(7). Parent-canceled Race yields Interrupt alone. A winning Race drains the same canceled loser; parent cancellation during the drain also yields Interrupt alone. Bool/Unit payloads remain correct when recovery changes the declared error channel to Never. Plain/framed reference and native reason/event projections agree with the independently authored Effect oracle.

The source-writing agent became unavailable; root completed the fixture, adapted the former refusal tests to scalar admission, and added Retry coverage. Online/source preparation and RETCONF decisions remain the basis for the test; the final 12-workload matrix passes both reference policies and native debug/release under None/Bounded (2/2 tests, 64.12s). Retry cancellation retains Fail(7) without another attempt; masked acquisition runs its catch, skips use after restoration and performs release. Existing fallible conformance/cost tests also pass.
