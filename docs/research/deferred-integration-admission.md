# Private Deferred integration admission

Prepared 2026-10-04 against installed Effect **4.0.0**. Reviewed AGENTS, PLAN, PROGRESS, deferred-budget, deferred-core/turns and retained-failure decisions before implementation. Retrieved the pinned [Deferred source](https://unpkg.com/effect@4.0.0/src/Deferred.ts) online; audited installed [evaluator](https://unpkg.com/effect@4.0.0/src/internal/effect.ts) as the authoritative primitive expansion. This record supplements DBUD-001..005 and TURN-009..012.

## Decisions

**DADM-001 — Internal analysis does not grant public support.** The new lexical nodes may be interpreted and analyzed privately. Compiler admission remains blocked until generated ownership, masking, complete independent-waiter cancellation and the bounded nested Race witness are verified. Existing `NESTED_TASK_GROUP` and cleanup-group refusals remain intact. An internal analysis must report capacities even when topology is rejected, so fixture measurements do not accidentally become supported compiler topology.

**DADM-002 — Audited scalar Deferred receipts.** Every node interpreter adds the common outer Suspend. `Deferred.make` and `isDone` return Sync, which evaluates once and returns Success: receipt 3. Scope adds a FlatMap to make and executes its body separately: plain 4; framed outward error decoration adds 2, giving 6. Complete evaluates its payload using expression try (2), adds FlatMap (1), then official succeed/fail aliases done/completeWith, returning Sync plus Boolean Success (2): plain 6. Framed expression decoration adds 2: framed 8. Cohort callbacks call `fiber.evaluate` synchronously and reset that waiter's counter; whole-invocation child sums already cover their continuations. Do not multiply or invent callback constants.

Await returns callback. On immediate completion it returns the stored scalar Success/Failure; on delayed completion the retained scalar exit is evaluated after resumption: callback + terminal = 2. Interrupted pending await executes its unregister Sync + Success (2), AsyncFinalizer primitive (1), combineCause OnFailure plus potential retained Fail (2), FlatMap (1), terminal interrupted failure (1), and potential mask restoration Fail (1). These alternative paths sum to 10, plus common Suspend = **11** plain. Framed await adds error decoration (2): **13**. This dominates the success path. Stored errors stay plain and each await occurrence constructs its own frame; no producer frame is retained. These receipts cover only the actual scalar interpreter expansions; changed interpreter wrappers require a new audit.

**DADM-003 — Default context is an explicit precondition.** Existing DBUD-001 assumptions still apply: default Scheduler/2048 budget, Clock/Tracer, no arbitrary hooks or outer host continuations, zero input Schema effects. Metadata capture opt-out is independent: turning frames off selects the plain receipt; it never removes scheduler/ownership requirements. This private checker can report an explicit unsupported-context diagnostic. Public integration must establish an executable context boundary or reject custom contexts; a boolean assertion from an end user is not proof. Changing the reference scheduler or disabling its automatic yield would change the conformance profile and is not an implicit workaround.

**DADM-004 — Distinguish capacity from startup order.** Group children sum simultaneous leaves; sequential and mutually exclusive branches take maximum. Leaf capacity, simultaneous task contexts (including group ancestors/root), and lexical Deferred owner count are separate measurements. Owner count deliberately sums scope occurrences over all edges, including mutually exclusive branches and shared DAG nodes; it is a conservative count of potential allocations over an expanded invocation, not distinct binder identities or maximum simultaneously live owners. Memoized summaries remain sensitive to the incoming callback-startup state and each occurrence adds its full owner summary. Existing bounded groups are 2/3 All or Race2; nested topology remains rejected. Creating a group after Await or Complete, including recovery or finalizer edges, is refused in the private coordinated topology profile because resumed callback startup has not been verified. Unbounded Repeat/Retry/ForEach and streams are refused rather than assigning finite capacity. Ownership binder validation belongs to core; these scheduling checks supplement it.

Topology tests exercise branch/sequence maxima, group sums, distinct owner counts, nested refusal, post-await completion/recovery/cleanup startup and loops. Keep existing budget/admission/cancellation tests green. These are private analysis gates; generated native conformance and costs remain separate release obligations.
