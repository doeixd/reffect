# Private generated Queue foundation

Current frame support: [QFRAME](queue-generated-frames.md) now verifies explicit private None/Bounded interruption diagnostics. The original preparation below retains its narrower initial gate; public admission and generated finalizers remain separate.

Preparation checked2026-10-07 against PLAN, PROGRESS, QIR/QCB/QOWN/QINT/QASYNC, existing lower.ts and the Latch generated/profile/growth machinery. This first checked lowering remains separate from public/compiler admission.

## Primary evidence

Published [Effect4.0.0 Queue.ts](https://unpkg.com/effect@4.0.0/src/Queue.ts) and [internal/effect.ts](https://unpkg.com/effect@4.0.0/src/internal/effect.ts) match installed bytes, SHA256 `6781fd0ac6fad03057ebeaa838d0f9723913027a4f6845d57dc3c17da70d1953` and `68c43e18e167d17b39f224d3793f11c7732cd857b7908ecd3ff1d1edf0affac2`. Queue capacity-release callbacks synchronously resume producers before the consumer receives its result; scheduled taker retry does not reserve payload. Existing private runtime traces establish those boundaries and controlled hosted cancellation. QASYNC explicitly excludes arbitrary host-future abandonment and intra-dispatch root cancellation.

## Decisions

- **QGEN-001 — Reuse compiler lowering.** Add an internal `lowerQueueFunctions` with its own checked profile map to lower.ts. Reuse scalar operation implementations, immutable helper captures and SourceWriter provenance rather than a separate handwritten IR compiler. Generic lowerFunctions, public Compile, RPC and exports retain QUEUE_NATIVE_UNSUPPORTED. A selected profile must not bypass signatures, hidden pure marker audits or unrelated functions.
- **QGEN-002 — Complete small ownership shape.** Exactly one root QueueScope, Bool/U64/Unit payload, Never channel, capacity1..3 and exactly one unconditional unnested All2 of Unit/Never children. Parent computation may have scalar composition/captures but no Queue operations. Offer/take only inside children. Refuse shutdown/end/Done, nested/mixed owners, Race, conditional/nested groups, inputs, Ensuring, Sleep, resource Scope and frames. Shutdown can introduce child interruption/fail-fast ordering; generic finalizer/Sleep lowering does not establish QASYNC markers/masking. Do not infer admission from local prototypes.
- **QGEN-003 — Borrowed route.** Invocation-local owner and group-local bridge, two pinned Unit-output wrappers, separate inherited child AsyncContexts sharing the existing parent watch receiver, and inline child success receipts. Helpers receive an optional QueueTask: parent has none, each child has its own task. Retain each child interruption result; successful driver completion alone is insufficient for successful All. No child channels, boxes/spawn, scalar metadata or Send promise. Entry is current-thread async and remains non-Send.
- **QGEN-004 — Independent bounds.** Extend the existing full-edge growth preflight for Queue only under its explicit coordination selection, then audit semantic types/owner binders/trusted expressions and unconditional group placement. Bound emitted Rust bytes and actual root layouts. Runtime step/depth assertions are prototype safety ceilings, not checked reference-operation/default2048 scheduler receipts. Public admission still requires those receipts, frames, owned execution and generated root costs.
- **QGEN-005 — Cancellation and validation.** Parent watch cancellation interrupts started children at Queue waits and awaits actual completion; guard retirement precedes borrowed future destruction. Compare emitted debug/release Rust with the official IR reference for repeated backpressure, capacity/payload variation, Boolean branches and scalar captures. Probe blocked parent interruption/preabort locally and against controlled reference cancellation. Keep QBF-UPSTREAM-001 refused by excluding end/shutdown topology. Source/profile refusal tests, negative continuation mutation, provenance checks and measured layouts/allocations accompany native tests. Native builds run serially.

## Alternatives and gates

Reusing ScanTask/Latch dispatch would erase Queue's inline callbacks/live retry semantics. A standalone source emitter would duplicate checked scalar lowering and mapping. Allowing all Queue IR nodes before their generated outcome/mask/frame adapters would turn runtime examples into unsupported admission claims. This profile proves a compiler-to-native path, not the complete Queue API. Public scheduler receipts, frame/Cause/Exit support, Done/shutdown fail-fast, generated async cleanup, broader timers/tasks and RPC ownership remain separate.

## Delivered path and evidence

`queue-generated-profile.ts` checks root ownership, exact builtin channels, unconditional group shape and full-edge source growth before `lowerQueueFunctions` selects the private route. Trusted expression auditing reuses the existing scalar audit through synthetic Succeed functions after the original function is checked; it does not execute callbacks or widen Deferred reference admission. Refusals point to the authored expression occurrence. The optional QueueTask and captured owner travel through existing helpers; SourceWriter preserves use/definition mapping and independent artifact opt-out. Actual emitted bytes and returned future layouts have separate limits.

Emitted Rust matches the official IR reference in debug/release for four-item repeated backpressure at capacities1/2/3, scalar captures/arithmetic/payload comparisons, Boolean false/true and Unit transfer. Controlled blocked cancellation matches reference interruption; preabort remains a local owned-boundary policy probe. Losing the inline producer continuation fails the bounded native watchdog. Independent profile/lowering review found no blocker within the tested shape. The native borrow checker caught overlapping layout-probe temporaries; each actual future is now measured and explicitly dropped before borrowing the context for the next probe.

Linux x86_64 debug/release returned future sizes are2176/2192/2208 bytes for the logged capacity1/2/3 pressure fixtures,1376 for Bool,1232 for Unit,1384 for blocked cancellation and2096 for quiet captured pressure. Construction of1000 quiet futures, execution of1000 quiet groups and one blocked cancellation each allocate0 times. Original parent watch/runtime/context creation is outside the measured region; receiver clones, both child contexts, owner, bridge, outcomes, driver and generated future execution are included. This uses empty inherited annotations/spans/request context and excludes logging; populated inherited metadata or different admitted programs may allocate. Payload scalars remain plain.

Shared growth validation also exposed a pre-existing test assertion mismatch: emitted-byte refusals have always said “Rust bytes”, while two assertions expected the internal key “rustBytes”. The assertions now match the actual diagnostic; the2MiB refusal remains enforced, including UTF-8 bytes across files. Native Deferred depth/branch/group boundary workloads still pass None/Bounded debug/release with their original layouts.

The later QBUD check is independent of QGEN source-growth limits: a finite small source can exceed the conservative retry budget and be refused before emission. It does not add runtime metadata or widen generic/public compiler support.
