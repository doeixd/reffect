# Effect control-flow helpers

Preparation checked 2026-10-02 against installed Effect **4.0.0-rc.118**, its [public API](https://cdn.jsdelivr.net/npm/effect@4.0.0-rc.118/src/Effect.ts) and [internal implementation](https://cdn.jsdelivr.net/npm/effect@4.0.0-rc.118/src/internal/effect.ts). Online source was downloaded before implementation; initial focused evidence used rc.118. The coordinated remote migration subsequently installed Effect 4.0.0 stable; the combined seven-suite regression passes 19/19 on stable. Existing [typed recovery](error-recovery.md), [resource registration](resource-scope-registration.md), and `ScopedIR.andThen` provide the relevant checked primitives. No new semantic nodes or native runtime are required.

## Decisions

- **EFF-001 — canonical recovery spelling.** Expose `catch` as the exact existing `catchAll` function, preserving compatibility and one recovery node. Only typed errors are caught; defects/compiler errors and interruption retain the existing bypass contract.
- **EFF-002 — generated composition.** `as`, `asVoid` and `tap` use existing Map/FlatMap nodes. `tap` accepts either a symbolic callback or a computation, executes only after success, retains the original successful value, and propagates callback failure and interruption. Error witnesses join under the existing equal-witness-or-Never rule. Replacement values are `Expr`, not arbitrary host values. Builders run during authoring, once; their IR executes conditionally later. No value wrappers, scheduler, crates or additional native metadata are introduced.
- **EFF-003 — conditional recovery.** `catchIf` admits a symbolic Boolean predicate and one recovery callback, with data-first/data-last forms. A nonmatching error is re-failed unchanged; matching recovery can fail or be interrupted. Error channels use checked witness joins, so incompatible unrepresented unions are refused. Upstream refinement overloads and optional `orElse` are deferred. Re-failing creates a new bounded logical trail under the established ERR-005 contract; retaining original Cause ancestry would require a different IR primitive.
- **EFF-004 — version and control-flow boundary.** Pinned v4 exposes `andThen`, not `zipLeft`/`zipRight`; retain the existing scope-aware `andThen` without adding legacy aliases. A general `matchEffect` cannot be implemented by catching `flatMap(source, onSuccess)`: that incorrectly catches success-handler failures. Use the Result slice’s `effectResult` bridge to capture only the source, then dispatch with `ResultIR.match` outside recovery. Handler errors therefore escape unchanged. This creates a plain checked tagged union locally; native specialization uses the existing representation and introduces no new node. Sequential array collection belongs to the collection-helper slice; concurrency is not admitted by these wrappers.

## Acceptance

Compare results and log traces with the pinned official combinators for successful/failed sources, callback failure, conditional recovery, nested cleanup and cancellation. Check channel inference without user casts, data-first/data-last forms, and incompatible witness refusal. Compile the same helpers to native code, assert reachable dependency selection, and run native conformance when the parent schedules Cargo validation. No broad Effect coverage follows from these helpers.

## Delivered evidence

Implemented `R.Effect.catch`, `as`, `asVoid`, `tap`, `catchIf` and `matchEffect`, with parent-owned public integration. `catch` shares `catchAll` by identity. `matchEffect` composes the Result bridge and tagged-union matching; a regression verifies that a successful source followed by a failing success handler escapes unchanged without invoking the failure handler. Builders remain symbolic and execute branches only when selected.

Focused command: `CARGO_PROFILE_DEV_DEBUG=0 CARGO_INCREMENTAL=0 vp test packages/reffect/tests/effect-combinators.test.ts --maxWorkers=1` passed **3/3**, **20.36s** total (**18.22s** tests), including fresh native debug/release builds. Evidence covers official/reference outcomes, native/reference outcomes, high-precision u64 preservation, source failure skipping both taps, tap failure propagation, matching/nonmatching conditional recovery, handler-failure isolation, cleanup/recovery log order and manually polled native cancellation awaiting cleanup. Disabled failure frames are used for this native fixture; bounded frame behavior remains governed by the existing primitives and their suites, rather than newly measured here.

Synchronous helper-only artifacts select no Cargo crates; the cancellation workload selects only the existing Tokio 1.53.1 dependency. Generated code has no `Box<dyn>` future. No allocation benchmark was added and no quantified speedup or zero-allocation claim is established. Focused formatting/lint/type checks passed with zero warnings/errors; package strict TypeScript (`vp exec tsc -p packages/reffect/tsconfig.json --noEmit`) passed after the final inference tests. Parent whole-workspace validation remains authoritative.
