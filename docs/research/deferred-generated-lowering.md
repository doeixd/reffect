# Private generated Deferred lowering

Prepared 2026-10-04 before source edits. Reviewed PLAN/PROGRESS, DIC/DIN/DADM/DPIPE, retained-outcome and composite-recovery decisions, current helper captures/emission and the real-context coordinator prototype. Checked published [Effect 4.0.0 Deferred](https://unpkg.com/effect@4.0.0/src/Deferred.ts) and [Tokio 1.53.1 unconstrained polling](https://raw.githubusercontent.com/tokio-rs/tokio/tokio-1.53.1/tokio/src/task/coop/unconstrained.rs) online against the installed versions. Synced through 095c3bd, preserving the separately owned RPC/Live/core-plan track.

**DGEN-001 — Generate privately before admitting publicly.** Keep Compile.plan and ordinary lowerFunctions refusal unchanged. Add an internal lowerDeferredFunctions entry point, absent from package exports, that validates a narrow profile before sharing the existing lowerer/emitter. This is a compiler integration experiment, not an executable public scheduler-context boundary. Explicit conditional default-context budget checks supplement but do not remove that public gate.

**DGEN-002 — Start with unnested, infallible coordination.** The initial generated profile uses zero-input scalar functions, scalar Deferred success with Never error, lexical owner scopes, synchronous expressions, Sleep, Log, ordinary composition, Match and Never-error Ensuring. All2/3 and sequential owner workloads are permitted; Race, nested groups, resource registration, streams, host/service operations, unbounded iteration and rich retained errors remain refused. Unsupported nodes fail explicitly rather than gaining partial emission.

**DGEN-003 — Borrow owners and route statically.** Owners are inline locals whose lifetimes contain every child future; helper signatures receive checked owner references separately from scalar arguments. One inline bank belongs to the invocation, with root slot zero and distinct reusable unnested child slots. No owner or bank enters AsyncContext, scalar values, globals or TLS. The generated profile records task/owner capacities separately and verifies lexical capture before lowering.

**DGEN-004 — Extend verified All semantics, not prototype join semantics.** Adapt the existing cooperative All2/3 cancellation/finalization contract with bank-aware polling. Child task wrappers acknowledge whole-task completion or verified primitive suspension. Artificial completion Pending never acknowledges a semantic prefix. Timers and awaits use the actual context adapter; broadcast is masked through the detached cohort. Parent cancellation must await children/finalizers. No forced host Drop/panic guarantee is introduced.

**DGEN-005 — Evidence before widening.** Independently authored official/plain/framed/generated traces must agree on registration order, synchronous waiter prefixes, first/losing/late completion, genuine timer suspension and cooperative parent cancellation/finalization. Compile generated Rust in debug/release and both frame policies, inspect borrow signatures and native layouts, and preserve ordinary-artifact dependency/runtime omission. Isolated owner allocations and whole invocation/executor costs remain separate measurements. Nested independent waiter cancellation, richer causes, executable reference-context enforcement and public exports remain later gates.

Alternatives rejected: public flags asserting scheduler safety, extending every scalar or AsyncContext with coordinator metadata, boxed task/owner registries, and using ordinary Tokio join/Waker broadcast without semantic ordering. Typed emission helpers should grow only where generated captures and calls need them.

**DGEN-006 — Diagnostic vocabulary follows generated boundaries.** Native interruption can occur at owner scope, await and completion. Keep these frame kinds in the logical-frame vocabulary and native envelope decoder while public planning remains gated. This aligns transport diagnostics with emitted private helpers; it does not claim exact interrupted reference/native frame-trail equivalence, which remains a public admission gate.

**DGEN-007 — Emit only selected coordinator families.** Generated private functions need the turn/context adapter and reached All arities, not the experimental join driver or an unused ordinary All driver. Retain prototype defaults for their independent tests, and select only private reached arities during generated emission. Ordinary functions sharing a module still select their ordinary driver. This reduces source/compiler work without claiming a binary-size improvement before measurement.
